# ADR 0014：播放器单一范围与临时默认列表

- 状态：Accepted；列表/队列部分由 [ADR 0018](0018-playlist-as-playback-sequence.md) 替代，完整播放器布局由 [ADR 0017](0017-full-player-as-main-content-view.md) 替代，最近播放决定由 rc.2 撤销
- 日期：2026-07-20，修订于 2026-07-24

## 决定

- 0.1.0 是纯本地播放器，不提供媒体库、文件夹索引、搜索、最近播放、专辑/艺术家聚合或封面数据库。
- 固定“默认”列表是会话内临时列表。外部打开媒体时，用同目录受支持音频的一次性上下文替换它并播放目标文件；普通冷启动显示空默认列表。
- 应用内手工添加只加入用户明确选择的文件，不自动扩展同目录。默认列表不持久化，也不允许重命名或删除。
- 用户播放列表持久化名称、顺序和路径。列表顺序是用户可见播放序列；不存在独立产品队列。
- 导航只包含默认/用户列表、工具和设置。完整播放器从底栏封面展开为主内容视图，按需读取当前曲目元数据、封面和歌词。
- 工具不进入播放主内容；音频压缩使用独立窗口，标签编辑后置。

## 理由与后果

临时默认列表承接一次性文件上下文，持久化用户列表承接明确收藏，二者语义清晰且不需要媒体库。删除低价值最近播放后，不再维护播放历史写入、跨窗口失效或隐私数据。SQLite 边界见 [ADR 0008](0008-persistence-storage.md)。
