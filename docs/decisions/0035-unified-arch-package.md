# ADR 0035：统一 Arch 包名与 alpha.4 重发

- 状态：Accepted；所有者于 2026-10-28 授权统一包名、更新文档、删除 alpha.4 Release/tag 并重新发布同版本。
- 修订 ADR 0031/0032 的预览与正式版分包规则；本次重发是所有者明确授权的单次例外。其他版本与发布保护保持不变。

## 决定

1. 当前通过 GitHub 分发并在应用内验签、由 Pacman 安装，不使用 AUR。Arch 包名固定为 `resona`，预览和正式版共用。资产命名 `resona-<Arch版本>-1-x86_64.pkg.tar.zst`；预览身份仅由 SemVer、Release Pre-release 和更新频道表达。
2. 打包、许可证路径、签名清单及更新器只接受统一身份。后续预览版到正式版可在相同包名下升级，保留严格更高 SemVer、包身份/架构/版本/摘要/事务和安装后数据库复核。
3. 所有者确认没有旧用户，不增加旧包名兼容、替换声明或自动迁移代码。测试环境若已装旧包，先卸载旧包再手动安装；应用标识与数据目录保持不变，卸载不删除用户数据和音频。
4. 版本保持 `0.3.0-alpha.4`。PR CI 通过后，在触发 main CD 前仅删除旧 `v0.3.0-alpha.4` Release、资产及同名 tag；合并 main 后由正式双平台签名 CD 重新生成，dev 快进同步。其他 Release/tag 不动，不从本机上传发包。
5. 同版本重新发布不会触发严格更高版本的自动更新；已有本次 alpha.4 测试安装应手动重装。此例外不变成自动覆盖已公开版本的常规规则。

## 验证

Node 与 Rust 验证预览/正式版的统一包名、清单身份和错误包拒绝；Arch PR CI 的隔离容器验证首装、升级、重装、预览到正式版、桌面注册及卸载。个人主机不运行 root 包回归，不改变系统签名策略。图形 Polkit 和实际跨版本应用内安装仍需实机验收。
