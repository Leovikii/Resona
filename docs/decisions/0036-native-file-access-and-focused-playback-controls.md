# ADR 0036：原生文件访问与窗口内播放快捷键

- 状态：Accepted；2026-10-29 所有者批准实施、测试与推送 dev；Windows 实机通过前不合并发布；所有者于同日确认 Windows/Linux 实机均通过并授权合并交付，最新双平台 CI 门禁保持。
- 对应：[0.3.0-beta.1 开发方案](../plans/0.3.0-beta.1.md)。
- 补充 ADR 0005、0018、0026、0028；不替代 Rodio 单引擎、CUE、列表或现有平台媒体控制边界。

## 背景

Dolphin 通过 KIO-FUSE 传给 Resona 的 NFS 文件可读，但本机父目录枚举为空。现有外部打开入口要求所选文件出现在同目录扫描结果中，因此在解码前失败。与此同时，应用当前呈现 GTK chooser，不自动共享 KDE 的 OMV 网络位置书签。

首个 beta 还需在应用获得焦点时用空格和方向键控制播放，音量变化须有可见反馈。前端轮询快照与现有滑块临时值不能成为快速相对操作的第二权威状态。

## 决定

1. **明确选择优先于目录发现**：验证并打开所选文件是主操作；同目录上下文只是扩展。扫描空/失败/漏项不能排除本来可读的目标，仍保留正常目录排序和同名 CUE 语义。目录降级与真正打开/解码失败分别返回类型化警告/错误。
2. **Rust 文件边界统一解析**：内核挂载、KIO-FUSE、portal 本地路径共用物理文件播放链。成熟 URL 解析处理文件 URI；Linux 的原始 NFS URI 经 KIO-FUSE 官方桌面接口映射，平台细节只留在 adapter。Rodio 不接收网络 URI，不新增协议播放引擎或应用自行 mount。
3. **桌面决定文件选择界面**：Linux 直接使用已锁定 ashpd 0.11.1 的标准 XDG FileChooser API；锁定的 Tauri dialog/rfd 会丢弃无法转为本地路径的 URI，且服务错误可能与取消混淆，Linux parent 未被设置，因此不经此包装调用。禁用插件默认 GTK chooser feature、保留 `xdg-portal` feature，KDE 使用系统 KDE backend。Windows 保留 Tauri dialog 的原生对话框并设置 parent。不启动 Dolphin 充当 chooser，不复制桌面书签或覆写用户系统配置。
4. **选择结果必须可读**：验证 portal 实际返回路径/URI与 Rust 访问权限，取消、服务失败、未知协议与文件错误分别诊断。KDE portal/KIO-FUSE 依赖和插件回退行为按锁定实现验证；回退界面不能替代 KDE 网络选择的验收。
5. **窗口内、控件优先**：主/压缩窗口只在可见、聚焦且没有模态/原生选择器阻挡时响应裸键；输入、IME、滑块、按钮、列表选择及其他原生/ARIA 控件先处理自身键盘操作。沿用桌面歌词焦点规则，不注册全局 hook 或全局快捷键。
6. **actor 计算相对动作**：空格切换、左右各 5 秒、上下各 10 个音量百分点在现有播放 actor 中按命令处理时的状态计算；复用现有暂停、继续、定位、音量方法并返回权威快照。限制到当前音轨范围和 0–100%；空格抑制重复，方向键重复输入有界。
7. **反馈不产生第二播放器**：主窗口复用音量 Popover 显示滑条/百分比，压缩窗口显示简短状态反馈；不移焦、不堆叠通知、不用未成功的命令更新成功数值。定位与既有拖动事务协调。
8. **拖放保留原始 URI**：锁定 Wry 的 GTK 后端将远端 URI percent-decode 后存入 PathBuf，可能损坏 `#`/`%`，且把 GTK 逻辑坐标标作物理坐标。Linux adapter 在 GTK SelectionData 边界保留 URI，沿用原生拖放生命周期；主/压缩窗口只消费 adapter 的统一逻辑坐标事件。Windows 沿用原生文件路径并按窗口缩放转换坐标。列表与压缩导入复用文件访问 adapter，在后台处理网络映射；不修改依赖源码或增加全局输入 hook。
9. **系统语言来自原生接口**：本机 WebKit 在系统 GLib 语言为中文时返回 `navigator.language = "C"`，只依赖它会误选英文。Linux 使用 GLib language_names，Windows 使用 GetUserPreferredUILanguages；支持 POSIX 与 BCP 47 语言名。窗口首次 React 渲染前初始化，手动选择优先；原生读取失败显式记录并回退 WebView。只激活已有 Windows crate 的 Globalization feature，不引入 locale 库或强制中文。

10. **网络目录直接使用 KIO**：所有者不接受永久禁用网络文件夹，也不接受以内核挂载作为前提。本机已复现 KIO NFS 列举的“.”为普通文件，KIO-FUSE 刷新该节点后可出现 ENOTDIR；应用通过 remoteUrl 还原来源，KIO ListJob 排除“.”/“..”后列目录，文件继续走已验证的物理映射与 Rodio。C++ adapter 静态编译进同一应用并动态链接系统 QtCore/KIO；仅在 re-exec 工作模式创建 QCoreApplication，先于 GTK/单实例初始化。工作模式无窗口，首次创建后以换行 JSON 串行复用 KIO 会话，Qt quit lock 保持事件循环直到父进程 EOF；每请求 15 秒任务期限、20 秒父进程读取兜底，失败回收、下一请求重建，限制条目/响应大小并验证子名称；普通目录仍用标准库。三个文件夹入口、同目录上下文、CUE、歌词、封面与压缩扫描共用目录边界；导入复用已列出的 CUE 候选。选择该最小补修，不引入 libnfs、新播放引擎或网络源迁移。

11. **保留平台 URI 的标准表示**：KIO-FUSE remoteUrl 返回 Qt 可读 URI，空格/方括号/中文不代表无效路径。KIO adapter 使用 QUrl TolerantMode，保留 NFS、主机与无 userinfo 校验；不手工拼接或反复解码 URI。
12. **共享导入互斥与反馈**：默认/用户列表、外部打开与压缩输入复用已有 file_task_gate，覆盖解析/扫描/提交，与转换、压缩扫描和安装互斥；忙时拒绝，不排队。主/压缩 UI 共用导入 gate 和 Rust busy/scanning 快照，200 毫秒后显示不遮挡正文的状态条，禁止重复添加/拖入，完成或失败释放，播放控制保持可用。不以未经测量的目录缓存换取速度。

## 后果与范围

- 原先按挂载类型禁止目录发现的临时保护已由 KIO 目录边界替代，恢复网络文件夹及伴随文件发现；不直接对故障 FUSE 路径执行 readdir。通过 GIO 挂载信息识别，不猜测运行时目录名。目录超时不等于全部 FUSE 文件读取具有同样的可中断保证。
- 可读单文件不再依赖同目录列举成功；不因此放宽格式验证、递归导入的链接限制或压缩文件提交规则。
- 文件选择、路径解析、文件可读、完整解码/定位和物理音频输出分别验证，不能相互替代。
- 不新增持久网络源模型或数据库迁移。beta.1 使用现有物理路径持久化，临时映射重启后可能失效，必须提示重新选择；永久 URI 恢复需要另行范围决定。
- 平台依赖变化需同步 Arch 包和许可证；KDE 原生集成需实机验收，键盘与 actor 边界需双平台自动/原生验证。
- 实现与验收分开记录；Linux 原生选择、NFS 与输出专项见本版验证文档，Windows 实机、真实网络中断和语言故障仍保留待验收项。portal 引入的 zbus Tokio feature 与现有 MPRIS 共用 runtime 上下文，保留 GLib executor；必须保留 MPRIS 原生回归。
