# ADR 0027：压缩活动分支、整体进度与关闭询问

- 状态：Accepted
- 日期：2026-10-19
- 所有者已同意 [0.2.1 UI 方案](../plans/0.2.1-ui.md)并授权实现与完整验证。
- 部分修订 [ADR 0016](0016-audio-compression-workspace-window.md) 的子目录展开约束；其余转换安全与窗口生命周期继续有效。

## 决定

- 主窗口关闭询问使用简短正文、“记住选择”和“隐藏到托盘 / 退出”两个直接动作。Esc/关闭按钮安全返回，初始焦点不落在退出上。提交中禁止重复提交并保留错误重试；不改变 Rust 偏好提交时机和活动任务退出确认链。
- 压缩项目首次观察为 running 时展开全部祖先目录，多 worker 取并集；不自动滚动、收起或抢焦点。手动收起在当前 taskId 内优先于新项目的自动展开；手动重开释放该分支抑制。新任务清除抑制，新扫描重置树状态，窗口重开只恢复仍活动的分支。
- 每目录继续按 200 项增量展示；未渲染分支的活动项目通过提示和“显示更多”访问。手动折叠目录显示活动数量；不为自动定位一次性渲染整棵树。
- 固定汇总栏使用文件行同款底色、百分比和状态，主窗口工具入口共用同一纯展示投影。文件等权，成功/失败贡献 1，待开始贡献 0，运行/取消沿用实际进度；活动批次最多显示 99%。100% 表示处理结束，成功与否由 Rust 终态和项目结果表达。
- 取消不补满未完成项目，成功体积与节省空间只统计成功项。进度可由辅助技术读取，自动播报只随批次状态变化；遵守减少动态效果。
- 终态固定栏改为醒目结果摘要：状态图标与标题、成功/失败/取消数量、成功项前后体积和实际源文件处理数量。无成功项不展示空体积统计；输出增大如实说明。源文件删除异常与转换失败分开表达，不能读取当前删除开关重写历史。
- 终态禁用转换动作；Rust 拒绝未重置的终态批次再次 start，并保持旧结果。添加/移除/清空输入在同一批次锁下拒绝活动任务和扫描，成功后重置任务并重扫输入；前端刷新权威任务快照并阻止请求重入。取消选择或失败请求不重置结果；选项变化不是输入变化。
- 所有展开状态仅在 React 窗口会话内存在；Rust 仍是任务、错误、终态、文件写入和退出的权威来源，不增加轮询、IPC 字段、依赖或持久偏好。

## 理由与验证

固定总进度弥补折叠与分页不可见性，活动分支展开降低查找成本，同时避免并行任务引发滚动争抢。保留已有安全边界和增量渲染，比合并退出状态机或新增虚拟化更符合本次 UI 范围。自动测试覆盖展开/抑制/快照时序和进度边界；浏览器及原生验收记录进入 [0.2.1 验证记录](../plans/0.2.1-validation.md)。
