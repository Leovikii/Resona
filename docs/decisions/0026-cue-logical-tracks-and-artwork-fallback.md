# ADR 0026：CUE 逻辑音轨与本地封面回退

- 状态：Accepted
- 日期：2026-07-28

## 决定

- CUE 音轨是 Rust 权威 `MediaSource`，包含物理音频路径、CUE 路径、曲号、可选元信息及毫秒起止区间。播放列表、默认列表和 Rodio 队列传递该结构，不把区间编码到路径，也不由 React 解析 CUE。
- 导入音频时仅查找直属目录中与音频同名的 `.cue`；有效且引用该音频的 CUE 将物理文件展开为逻辑音轨。无效、不可读或不匹配时保留普通音频，不阻断同批导入。
- Rodio 仍是唯一播放引擎。逻辑音轨在解码源上应用起点与可选终点，向 UI 暴露相对位置和相对时长；上一首、下一首、重复、随机和预加载仍按队列项工作。
- 播放列表轻量摘要由 Rust 读取物理音频时长；共享同一文件的 CUE 项复用该摘要并按权威起止区间得到逻辑时长。React 可按现有目录展示结构合计这些类型化时长，但不得自行探测音频或猜测未知值。
- 当前曲目封面优先使用内嵌图片；缺失时只扫描直属目录的 JPEG/PNG，依次选择不区分大小写的 `cover` 文件、唯一图片、多图中的小尺寸方图。扫描条目、源字节、像素与缓存均有上限，候选排序确定且不建立全局索引。
- CUE 元信息覆盖逻辑音轨的标题、表演者、专辑和曲号，音频属性及封面继续来自物理文件；平台投影与 UI 共享同一归一化封面。

## 理由

显式逻辑源让同一文件的多个音轨在持久化、播放和界面中保持可区分，并避免路径字符串协议。按需、有界的直属目录回退符合播放器范围，也能复用现有按内容指纹去重的封面缓存，而不会演变为封面数据库。
