## 风险与限制

- Windows topmost 是共享层级；独占全屏、安全桌面及持续争夺置顶的程序不在无条件覆盖承诺内。
- 文件选择窗口低频阻塞、多显示器与 DPI 条件见[已知问题](KNOWN_ISSUES.md)。
- 32-bit integer/float WAV 转为 24-bit FLAC；不支持播放 32-bit FLAC。
- 当前发行平台为 Windows x64 NSIS；Linux 需独立计划。0.1.0 未使用 Authenticode，updater 签名不能视为 Windows 发布者身份签名。
