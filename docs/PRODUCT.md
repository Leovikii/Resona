# 产品范围

## 定位

Resona 是本地优先的桌面高解析度音频播放器。0.1.0 专注可靠播放、清晰的播放列表、低干扰界面和桌面歌词，不管理用户的外部媒体文件夹，也不建设本地媒体库。

## 0.1.0 Windows 发行范围

- MP3、PCM WAV 和 FLAC 播放
- 44.1 kHz/16-bit 至 192 kHz/24-bit 的常见双声道本地音频
- WAV 32-bit integer/float 源文件播放；FLAC 32-bit 不支持并返回可恢复的解码错误
- 播放队列、播放模式、定位、音量和设备选择
- Windows WASAPI Shared、板载声卡和 Windows 蓝牙音频端点
- Windows SMTC 媒体会话、耳机和键盘媒体键
- 临时默认播放列表、持久化用户播放列表和最近播放
- LRC、SRT、WebVTT 本地歌词与独立桌面歌词窗口
- 跟随系统或手动浅色/深色模式、有限主题色、中文简体和英文
- 当前曲目的按需元数据、音频参数、封面和歌词展示
- WAV 到 FLAC 的“音频压缩”工具
- Windows 安装、托盘、主动检查更新、本地设置、窗口状态和错误诊断

音频压缩、托盘和 Tauri updater 在核心播放与界面交互稳定后实现，不影响前期版本的模块边界。标签编辑不会进入 0.1.0。

## 信息架构

主窗口默认使用“左侧导航 + 右侧主内容 + 底部播放器”的宽屏结构。设置页可显式切换窄屏模式；窄屏保留常驻单图标导航栏，显式展开侧面板复用完整导航，主内容单列展示，底栏以两行直接展示全部播放与辅助控制。布局模式不随窗口宽度自动切换。

侧栏从上到下为：

1. 最近播放。
2. 轻量分隔线。
3. 播放列表分组标题与新增按钮。
4. 固定的“默认”子项。
5. 用户创建的持久化播放列表。
6. 底部“工具”和“设置”。

普通冷启动默认打开“最近播放”；从系统或应用内打开媒体时切换到“默认”详情并开始播放目标文件。不再提供“文件夹”“媒体库”或侧栏“正在播放”标签页。点击侧栏列表只在右侧显示其详情；双击详情中的曲目是明确播放动作，会把该列表顺序作为当前播放序列并从目标曲目开始。完整播放页由底部播放器展开为主内容区的互斥视图，关闭后恢复原来的列表上下文；点击导航会自然退出完整播放器并显示目标页。窄屏下该视图隐藏大封面但保留歌词与播放信息，不创建第二份播放状态。

工具页只展示“音频压缩”和后续“标签编辑”等工具入口，不直接铺开工具控件。0.1.0 点击“音频压缩”后打开或聚焦单实例普通工作窗口；压缩参数、文件/文件夹拖入、递归扫描、目录树、任务进度和结果均在该窗口中完成。

## 列表与播放来源

- 当前播放列表就是用户可见的待播放序列，不提供第二个可编辑 `PlaybackQueue`。
- `DefaultPlaylist` 是会话内临时集合，应用重启后为空，不写入 SQLite。
- `UserPlaylist` 是用户显式创建并持久化的待播放序列，同一文件可存在于多个列表。
- Rodio actor 保留当前索引、预载 source 和随机遍历所需的内部执行序列，但它不是第二个产品集合。
- `RecentPlay` 是有限长度的播放事件历史，不是媒体库或播放队列。

打开单个音频时，Resona 读取该文件所在目录的直属支持音频，按稳定文件名顺序更新默认列表并从目标文件开始播放，不扫描子目录。如果重新打开同目录文件，Resona 仍以低成本枚举得到路径快照；快照相同且目标存在时复用当前默认列表，只切换目标，不重建列表或发布无意义更新。目录内容变化时才原子替换默认列表。

该行为统一覆盖应用内文件选择、命令行参数、Windows 文件关联和第二实例转发。正式安装包注册文件关联之前，通过命令行参数验证相同协议。

用户可以新建、重命名和删除播放列表，并通过按钮或拖入添加文件。拖入已展开列表时，释放位置决定插入位置；按钮添加默认追加到底部。将外部文件拖到侧栏播放列表之间的间隔时，在该位置自动创建新列表，名称优先使用共同父文件夹名，冲突时使用稳定缺省名称。

列表页不提供“载入队列”“追加队列”、独立队列抽屉或把当前序列复制回列表的同步按钮。主内容视图只显示一个标题，播放状态只由底部播放/暂停按钮表达；当前列表由侧栏播放中标识指出。

## 元数据与歌词

Resona 只为当前播放页或明确的列表展示按需读取元数据，不维护全局 `media_records`、外部文件夹索引、搜索库或封面数据库。损坏标签不能阻止音频播放；文件路径和原始标签保持原文。

歌词来自音频同目录的 LRC、SRT 或 WebVTT sidecar，支持同名、音频格式限定名和语种限定名。桌面歌词提供透明、置顶、锁定穿透、原生解锁、移动和播放控制，并允许调节字号、颜色、文字透明度和空闲背景透明度。

桌面歌词未锁定且鼠标进入窗口时，背景临时切换为统一的交互透明度，以明确窗口边界并保证顶部控件可读；离开后恢复用户设置。锁定状态保持整窗穿透和原有背景，不通过全局鼠标监听改变整窗视觉，只有原生解锁热点响应 hover。

时间行切换使用固定高度的两行滚动槽：旧当前行向上淡出，下一行进入当前位置，新下一行从下方进入。跨多行 seek、歌词 revision 变化或减少动态效果时直接定位，避免连续追赶动画。如果目标平台无法稳定完成该动画，降级为只显示当前行，不保留生硬刷新的下一行。完整播放器的歌词行可点击或通过键盘激活并跳转到该行开始时间；桌面歌词不增加该手势，以免与窗口拖动和锁定穿透冲突。

平台窗口能力通过统一 capability/facade 隔离；Windows 使用 Win32/WebView2 adapter，未来 Linux 根据 Wayland 实际能力实现或降级。

## 音频压缩

0.1.0 的格式转换统一命名为“音频压缩”，只承诺 PCM WAV 到 FLAC。三档“快速、平衡、最小体积”只影响编码时间与体积，均为无损；16/24-bit 保持位深，32-bit integer/float WAV 输出 24-bit FLAC，采样率与声道保持。实现使用固定版本 FFmpeg sidecar，必须提供任务进度、取消、输出冲突处理、临时文件、成功后原子落盘和失败清理；默认不覆盖已有输出，也不宣称对有损源进行无损提升。

压缩工作窗口接受文件和文件夹选择或拖入。文件夹由 Rust 后台递归扫描所有普通子目录，并按导入根路径的相对目录结构展示验证通过的待转换 WAV；重叠路径去重，默认不跟随 junction、符号链接或其他 reparse point。无法访问的项目形成可见警告，不阻断其余扫描；扫描可取消且不得阻塞主窗口或播放。

“成功后删除源 WAV”默认开启并可关闭；开启时每批任务开始前必须弹窗确认。只有 FLAC 参数校验通过并原子落盘后才能删除对应源文件，取消、失败、冲突或校验失败均保留源文件。

AIFF、批量格式扩展和标签编辑在 0.1.0 之后评估。

## 更新、托盘与生命周期

Tauri updater 用于用户主动检查更新及确认后安装，不进行强制更新，不引入账户、遥测、联网激活或后台静默下载。更新失败不得影响本地播放。

托盘与关闭行为在发布阶段单独确定。在新 ADR 接受前，当前规则仍是关闭主窗口即退出，停止播放并销毁桌面歌词资源；不能先加入托盘图标再把关闭语义悄悄改成后台运行。

## 可延后能力

- 标签编辑
- AAC/M4A
- 在线歌词或元数据提供商
- 系统文件夹管理、媒体库索引、搜索、专辑/艺术家视图和实时监听
- AIFF 或其他格式压缩
- 播放列表的文件夹递归导入、智能列表和复杂自动分类；音频压缩窗口内的一次性递归扫描除外
- 复杂 DSP、频谱、波形和可视化
- 视频播放
- Linux 实现与验证

## 播放输出边界

- 0.1.0 不实现 WASAPI Exclusive、ASIO 或 bit-perfect 输出。
- Windows Audio Engine 负责把不同源采样率转换为用户配置的共享模式输出格式。
- Resona 分别展示源文件参数和当前输出设备，不把蓝牙链路标记为高解析度直通。
- 不承诺 FLAC 32-bit、APE、DSD、DoP、模块音乐或未进入发布测试矩阵的格式。

## Linux 结构预留

未来 Linux 只以 Wayland + PipeWire 的现代桌面为目标。Windows 0.1.0 只保留音频输出、系统媒体会话和桌面歌词的 capability/adapter 边界，不实现、不测试，也不承诺 Wayland 上与 Windows 完全一致的窗口行为。

## 非目标

- 自研解码器、标签格式或转码引擎
- 管理、复制或接管用户外部媒体目录
- WASAPI Exclusive、ASIO、bit-perfect、DSD 或 DoP 宣称
- 在线账户、云同步、强制更新或流媒体商店
- 为旧版 X11、PulseAudio 或老旧发行版投入兼容成本
- 将播放器变成通用视频播放器
- 通过大量自定义基础控件建立新的 UI 框架
