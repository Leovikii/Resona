# 产品范围

## 定位

Resona 是本地优先的桌面高解析度音频播放器。它优先提供可靠播放、清晰的输出状态、低干扰媒体库和桌面歌词，而不是在线音乐服务或内容平台。

## 首个 Windows 版本

首版计划包含：

- MP3、PCM WAV 和 FLAC 播放
- 44.1 kHz/16-bit 至 192 kHz/24-bit 的常见双声道本地音频
- AAC/M4A 尽力支持，不作为首版发布阻塞项
- 播放队列、播放模式、定位、音量和设备选择
- Windows WASAPI Shared 输出
- 板载声卡和 Windows 蓝牙音频端点
- 本地目录扫描、媒体库、搜索和封面
- LRC 歌词与独立桌面歌词窗口
- 桌面歌词置顶、透明、锁定穿透、解锁移动和交互
- 元数据读取
- WAV/AIFF 等未压缩音频转换为 FLAC
- 转换队列、进度、取消、冲突处理和元数据保留
- 本地设置、窗口状态和错误诊断

## 可延后能力

- 元数据编辑
- 在线歌词或元数据提供商
- 复杂 DSP
- 高级频谱、波形和可视化
- 视频播放
- Linux 实现与验证

## 播放输出边界

- 首版不实现 WASAPI Exclusive、ASIO 或 bit-perfect 输出。
- Windows Audio Engine 负责把不同源采样率转换为用户配置的共享模式输出格式。
- Resona 分别展示源文件参数和当前输出设备，不把蓝牙链路标记为高解析度直通。
- 不承诺 APE、DSD、DoP、模块音乐或其他长尾格式。

## Linux 结构预留

未来 Linux 只以现代桌面为目标：

- Wayland
- PipeWire

首个 Windows 版本只保留播放输出和桌面窗口能力边界，不实现、不测试，也不承诺 Wayland 上与 Windows 完全一致的窗口行为。

## 非目标

- 自研解码器、标签格式或转码引擎
- WASAPI Exclusive、ASIO 或 bit-perfect 宣称
- DSD、DoP 和未进入发布测试矩阵的长尾格式
- 在线账户、云同步或流媒体商店
- 为旧版 X11、PulseAudio 或老旧发行版投入兼容成本
- 将播放器变成通用视频播放器
- 通过大量自定义基础控件建立新的 UI 框架
