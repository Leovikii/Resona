# 产品范围

## 定位

Resona 是 Windows 优先的本地桌面音频播放器。0.2.0 在既有本地播放、播放列表、歌词、Windows 集成、WAV 无损压缩和安全更新之上增强本地专辑体验，不演变为媒体库或在线服务。

## 当前范围（0.2.0）

- MP3、WAV、FLAC 本地播放及同名 CUE 逻辑音轨，支持播放/暂停、定位、音量、上一首/下一首、连续播放和输出设备选择
- 临时“默认”播放列表与持久化用户播放列表；播放列表顺序就是当前播放序列
- 当前曲目的标题、艺术家、专辑、音频参数、封面和本地歌词
- 完整播放器、桌面歌词、SMTC、任务栏媒体控件/进度/封面预览、托盘与文件关联
- PCM WAV 到 FLAC 的独立压缩工作窗口
- 单实例、窗口几何与主题偏好、NSIS 安装、Tauri updater 与自动发布链

不提供最近播放、文件夹媒体库、全盘索引、搜索、智能列表或封面数据库。

## 信息架构

宽屏左侧依次显示品牌、固定“默认”列表、用户播放列表、新建入口、工具和设置。窄屏使用顶部主导航与播放列表 Tabs，功能与宽屏一致，不维护第二份状态。

冷启动选择“默认”列表。应用内或系统外部打开媒体时，用该媒体所在目录的一次性上下文替换默认列表并开始播放目标文件；手工添加只加入明确选择的文件，不自动扩展同目录。默认列表不持久化。

用户播放列表持久化名称、顺序、文件路径、CUE 逻辑音轨区间，以及文件夹导入时的根目录上下文。导入音频时，同目录同名 CUE 会把对应物理文件展开为可独立显示、定位和切换的音轨。文件夹导入递归加入受支持音频，并在列表中以可折叠目录层级呈现；顶层导入目录首次显示时展开，子目录默认折叠。展开状态按列表在当前会话内记忆，不写入数据库；目录节点只组织当前列表，不监视或索引文件系统，折叠状态不改变播放顺序。单击列表只切换详情；双击曲目才激活该列表为播放序列并从目标曲目开始。删除正在播放的曲目后按可预测顺序继续，删除整个活动列表时停止并清空播放上下文。

底部播放器始终存在并显示当前封面；点击封面在列表视图和完整播放器之间切换。最右的播放列表按钮返回权威当前播放列表，展开当前歌曲的祖先目录并定位该行；自然切歌不自动展开目录、滚动列表或抢占焦点。切换视图不能重建播放状态、改变序列或丢失列表上下文。

## 元数据与歌词

元数据只为当前曲目和明确展示的项目按需读取。播放列表主标题优先显示标签中的音轨号与标题，缺失字段不占位，标题缺失时至少回退为不含扩展名的文件名；不再重复显示已由目录树表达的完整路径。右键“文件信息”按需展示标签、音频参数和文件路径，并可通过跨平台系统 opener 在文件管理器中定位原文件。损坏标签不能阻止播放；缺失值不猜测不存在的信息。

当前曲目封面通过有界缓存共享给底栏、完整播放器、SMTC、托盘投影和任务栏预览。优先取内嵌封面，其次取同目录 `cover` 图片、目录唯一图片、多图中的小尺寸方图；候选扫描、源图、解码尺寸和缓存均有上限。无有效封面时使用统一占位图，缓存不得扩展为全库索引。

歌词支持同目录同名 `.lrc`、`.srt` 和 `.vtt`。同步歌词支持当前行高亮、点击定位与偏移；桌面歌词的极长行在该行展示时间内从头到尾线性滚动一次，暂停和定位会同步动画。桌面歌词始终是 Rust 管理的独立原生窗口，不复制播放核心。

## 音频压缩

只承诺 PCM WAV 到 FLAC。快速、平衡、最小体积三档均为无损；16/24-bit 保持目标位深，32-bit integer/float 输出 24-bit FLAC，采样率与声道保持。

FFmpeg 是按需下载的固定运行时依赖，不进入安装包。扫描和结果校验在进程内完成；批次使用有界文件级并行。每项必须具备独立进度、源/输出体积和终态；输出冲突不覆盖，临时文件失败或取消时清理，验证后原子提交，只有提交成功才允许删除源 WAV。

窗口接受文件、文件夹和拖入。文件夹在 Rust 后台递归扫描，路径去重，不跟随 junction、符号链接或 reparse point；单项错误形成警告，不阻断其他文件。界面在转换前显示输入总体积，结束后只按成功项计算输出总体积和节省空间。

## 更新与生命周期

关闭主窗口按 Rust 偏好询问、隐藏到托盘或退出；最小化保持普通任务栏行为。退出时统一停止播放、辅助窗口、扫描/压缩任务和托盘。

应用首帧后每进程静默检查一次更新，不静默下载、不强制安装、不上传遥测。发现更高 SemVer 后显示 Markdown 更新日志，用户可直接安装；设置仍提供主动检查和预览版本开关。网络、GitHub 或签名失败不得影响本地播放。

0.1.0 只发布 Tauri NSIS `currentUser` x64 安装包。Tauri updater 签名负责更新完整性；Windows Authenticode 是可选的发布者身份能力，不作为 0.1.0 门禁，也不进入跨平台构建边界。

## 非目标

- 在线账号、串流、商店、推荐、遥测或云同步
- 媒体库、最近播放、文件夹监视、数据库搜索、标签编辑
- AIFF/其他格式转换、有损转码或“无损提升”
- DSP、均衡器、响度归一化、Exclusive/bit-perfect 声明或第二播放引擎
- 移动端与 Web 版

Linux 只保留平台 adapter 边界；0.1.0 不承诺 Linux 发行物。
