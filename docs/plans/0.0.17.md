# 0.0.17 发行前界面与音频压缩工作区收口

- 状态：Completed
- 日期：2026-07-20
- 接受依据：项目所有者确认播放器内容层级、拖放热区和音频压缩独立窗口设计，并要求开始开发与浏览器前端验证

## 范围

- 将完整播放器从绝对定位覆盖层改为右侧主内容区的互斥视图；底部播放器稳定挂载，侧栏导航会自然退出完整播放器。
- 完整播放器和底栏使用连续、不透明的主题表面，移除展开状态下的视觉白边；界面标签使用“歌词”/“Lyrics”，不暴露“同步”实现术语。
- 外部拖放期间扩大侧栏播放列表间隔和列表内部插入间隔，提供稳定插入线与轻量展开动画，不使用持续改变命中几何的高频动画。
- 主窗口工具页只保留音频压缩入口和活动任务摘要。
- 新增单实例普通 `audio-compression` Tauri WebView 工作窗口、最小 capability 和窗口位置/尺寸恢复。
- 新增 Rust 权威的文件/文件夹导入、普通子目录递归扫描、路径去重、链接边界、格式验证、扫描取消、警告和目录树快照。
- 压缩窗口完成选择/拖入、目录树、移除、压缩档位、安全删除确认、进度、取消和结果展示；关闭/重开窗口恢复服务状态。

## 非范围

- 新图标、NSIS/MSI、文件关联、托盘、Tauri updater、签名和正式发行托管。
- 标签编辑、媒体库、播放列表递归导入、在线能力或 Linux 实现。
- 改变 0.0.16 已验证的 FFmpeg 编码参数、输出位置和源文件安全顺序。

## 验收

- Rust 单元/集成测试覆盖嵌套目录、重叠根、大小写 WAV、非 WAV、符号链接/重解析点、不可访问项、取消和快照恢复边界。
- TypeScript/Vite build、Rust format/test/Clippy、许可证报告和 `git diff --check` 通过。
- 浏览器验证主窗口与压缩窗口的中文/英文、浅色/深色、常用桌面尺寸和最小尺寸；检查控制台无 warning/error。
- 浏览器验证完整播放器与普通内容互斥、侧栏切换自然、展开页无透明底和白边、文案正确、拖放指示区域稳定。
- Windows 原生验证压缩窗口单实例聚焦、关闭重开、文件/文件夹选择、外部拖放和真实 WAV 到 FLAC 安全流程。

## 完成定义

- 上述行为与 ADR 0015/0016 一致，错误可诊断且前端不复制扫描/转换领域状态。
- `docs/STATUS.md`、架构和发行记录与实际测试结果一致。
- 发行工程尚未决定的能力继续明确标记为后续，不因版本号进入 0.0.17 而被隐式实现。
