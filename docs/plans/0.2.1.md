## 完成范围

1. 精简关闭询问的中英文正文、记忆选项和按钮，保留“隐藏到托盘 / 退出”与活动任务二次确认。安全初始焦点、Esc 返回、提交中互斥与错误重试已实现。
2. 压缩项目首次进入运行状态时展开全部祖先，多 worker 取并集；手动折叠抑制同批次后续自动展开，手动重开释放该分支，新任务/扫描按方案重置。不自动滚动、收起或抢焦点。
3. 固定汇总栏加入文件行同款进度底色、处理状态与百分比。主窗口工具入口共用投影；失败计入已处理，取消保留实际进度，成功体积不混入失败项。提供可访问进度、批次状态低频播报与减少动画支持。
4. 终态采用醒目结果汇总，展示实际成功/失败/取消、体积及源文件处理结果；禁用旧批次转换并在 Rust 服务层防止重复启动。只有明确变更输入才重置结果并重扫。
5. 每目录仍按 200 项增量展示；后续未渲染条目的活动数量明确提示，手动折叠目录显示活动数量。

编码参数、文件提交/删除顺序、worker 数、播放逻辑、压缩窗口生命周期与发布链保持既有约束。不新增依赖、全局设置、轮询或持久化目录展开状态。Rust 两处像素遍历改用等价标准库固定长度分块 API，以通过当前工具链 Clippy。
