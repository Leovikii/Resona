# 0.0.18 播放列表交互与 UI 冻结

- 状态：Completed
- 日期：2026-07-22
- 前置条件：项目所有者确认本计划，并在开发开始前集中补充剩余 UI 调整意见

## 目标

关闭 0.1.0 发行前仍影响日常使用的交互缺陷，完成最后一轮界面收口并冻结功能界面。该阶段不引入安装器、托盘、更新器或新的播放器能力。

## 范围

### 外部文件拖入播放列表

- 修复 Windows/Tauri 外部文件无法加入用户播放列表的问题；Rust 服务继续负责路径校验、去重、插入和错误结果，前端只表达目标列表与插入位置。
- 拖到侧栏用户播放列表行时追加到列表底部；拖到已展开列表的曲目间隔时按释放位置插入。
- 拖到侧栏用户播放列表之间的间隔时，在对应位置新建列表并加入有效文件；名称沿用 ADR 0014 的共同父文件夹/稳定缺省规则。
- 内部曲目拖动只用于同一播放列表重排，不得被识别为外部导入，也不得允许把播放列表曲目拖到侧栏或应用外形成无意义操作。
- 不支持的格式、目录、重复路径和读取失败必须返回可见、可诊断的分类计数；部分有效时允许提交有效项，不静默吞掉拒绝项。
- 默认列表的空列表区域接受多个文件或文件夹拖入并追加到会话列表；非空曲目滚动区按行中线计算插入位置，并复用内部排序的扩展间隔和插入线反馈。标题、来源路径和右侧控件不属于热区。文件夹只展开直属受支持音频。该入口不得把默认列表持久化；默认列表为当前列表时同步插入内部播放序列，非当前时不影响播放。
- 默认列表和用户列表使用一致的单一“添加”菜单按钮，菜单内分别提供文件与文件夹选择；用户列表继续按 SQLite 事务持久化，默认列表继续归 Rust `MediaImportService`。

### 播放列表即播放序列

- 按 ADR 0018 删除产品层独立播放队列。默认列表是未保存列表，用户列表是已保存列表；点击曲目激活该列表，当前列表的追加、插入、删除和排序直接更新后续播放顺序。
- Rodio actor 保留预载、连续播放、随机遍历和失败隔离所需的内部执行序列，但主窗口不单独显示或编辑它。
- 删除公开队列替换/追加/删除/排序 commands；用户列表激活只提交列表 ID 与项目 ID，Rust 读取权威列表并开始播放。
- 底栏不提供独立队列抽屉或重复的列表定位按钮；侧栏播放中标识负责指出当前列表。删除当前持久化列表时，把既有序列转移为默认临时列表；默认列表退出后不恢复。

### UI 最终收口

- 集中处理项目所有者尚待补充的 UI 微调，避免分散修改造成重复返工；接受后冻结 0.1.0 的页面结构和主要控件位置。
- 优化完整播放器“播放信息”排版，建立曲名、艺术家/专辑、输入音频、系统输出和文件路径的清晰层级。
- 输入/输出技术信息优先保持稳定单行；长元数据和长路径必须有明确的换行、省略或可查看策略，不能依赖偶然裁切，也不能引起切换栏或底栏位移。
- 检查激活/悬停优先级、重复标题/状态、控件间距、文本溢出、滚动条、焦点态和切换动画；不得重新引入已删除的重复状态或队列操作。

### 窄屏收口（ADR 0021）

- 窄屏导航使用顶部全局导航 + 横向播放列表 Tabs；删除固定左侧 rail、Drawer 和重复 Sidebar。
- 窄屏底栏使用紧凑两行布局：第一行曲目信息/进度/时间，第二行音质、核心播放控制、模式/桌面歌词/音量。曲名沿用按需悬停滚动，控件不得因长标题换行。
- 设置页歌词字号与歌词颜色统一为单行两列设置行；此项仅调整布局，不复制偏好或歌词领域逻辑。
- 播放/暂停等即时 command 不切换全局 busy。普通内容视图使用稳定 callback/对象引用和 memo 边界，播放状态与 750 ms 进度刷新不得重挂载列表、设置或工具页，也不得重新触发页面入场动画。
- 默认列表的来源路径必须占据可收缩 flex 轨道；内容为空或长路径时，“添加”按钮均保持固定宽度并完整位于标题区域内。

### 定位交互、滚动容器与主窗口状态（已接受并实现）

本补充范围由项目所有者于 2026-07-21 提出并于 2026-07-22 接受实现；不提前进入 0.0.19。

#### 无回跳定位事务

- 修复进度 Slider 释放或点击后的视觉回跳。当前问题是 `onChangeEnd` 在 `seek_playback` 返回前先结束本地 seeking，导致旧快照短暂覆盖目标值。
- 前端建立单一 seek transaction：拖动/点击时立即显示目标值；提交后继续固定该值，直到对应 command 成功快照或后续权威位置确认接管。失败时才恢复最新权威位置并显示现有结构化错误。
- 连续快速定位必须以递增 transaction ID 丢弃旧请求的迟到结果，不能让第一次 seek 覆盖第二次目标。该状态只属于播放器交互，不进入全局 busy，也不阻塞暂停、音量或页面内容。
- Slider 与歌词点击复用同一个 `requestSeek(positionMs)` 回调和现有 `seek_playback` command，不新增第二套定位协议。

#### 歌词点击定位

- 完整播放器中的每行歌词改为可聚焦的按钮语义；单击或键盘 Enter/Space 跳转到该行 `startMs`，时间仍来自 Rust 权威解析后的 `LyricsLine`。
- 无当前曲目、不可定位或 command 正在失败恢复时禁用跳转；目标值按当前曲目时长安全约束。跳转成功后沿用现有活动行居中和减少动态效果规则。
- 桌面歌词窗口不加入点击定位：未锁定状态需要保留窗口拖动，锁定状态要求鼠标穿透；把 seek 手势加入该窗口会破坏既有平台交互边界。

#### 统一组件滚动条

- 盘点所有可见原生滚动容器。设置页、侧栏播放列表、完整播放器播放信息、窄屏主内容和其他会显示滚动条的区域改用 Mantine `ScrollArea`；已有播放列表和压缩目录树继续复用同一组件。
- 完整播放器歌词可继续默认隐藏滚动轨道，但滚动 viewport 也由 `ScrollArea` 提供并保留活动行 ref/居中能力。不得同时保留父子两层纵向滚动。
- 统一使用细轨道、主题 token、hover/auto 可见策略和键盘/滚轮行为，不通过全局 `::-webkit-scrollbar` 重新绘制一套自有滚动条。

#### 主窗口几何与显式窄屏模式

- 按 Accepted ADR 0020 增加设置项“界面布局：宽屏 / 窄屏”。默认宽屏，不根据窗口宽度自动切换。
- Rust/Tauri 在主窗口首次显示前恢复布局模式和该模式独立保存的位置、尺寸、最大化状态；不恢复最小化或全屏。显示器消失或 DPI 改变后约束到可见工作区。
- 宽屏保持 `1080×700` 默认、`760×520` 最小尺寸和现有两列应用壳。窄屏使用 `420×720` 默认、`360×600` 最小尺寸，并复用现有选择、列表、播放器和设置状态。
- 窄屏使用顶部全局导航和横向播放列表 Tabs，不保留折叠侧栏入口；底栏使用 `120px` 稳定两行结构，第一行容纳曲目信息、进度和时间，第二行通过 Mantine `xl` 控件直接展示音质、上一曲/播放暂停/下一曲、播放模式、桌面歌词和音量。完整播放器隐藏大封面，只显示曲目信息与歌词/播放信息面板。
- 列表添加、删除选中项、重命名、右键、排序、工具入口、设置和完整播放器在窄屏均必须可达；长路径和双语文本不能产生横向页面滚动。
- 底栏曲名在溢出时自动滚动，侧栏播放列表名只在 hover/focus 时滚动；实现只使用尺寸变化观察和合成层动画，减少动态效果时退化为省略。大量曲目行不启用滚动文本。

### 列表选择、右键菜单、音质标识与桌面歌词工具栏

项目所有者已于 2026-07-21 确认本批收口项；默认列表退出语义和桌面歌词工具栏布局由 ADR 0019 固定。

#### 底栏与播放中提示

- 移除底栏的“定位当前播放列表”按钮和桌面歌词锁定/解锁按钮。桌面歌词的锁定控制只存在于歌词窗口；底栏仍只负责歌词窗口显示/隐藏。
- 底栏中央固定为“上一曲、播放/暂停、下一曲、停止”，右侧固定为“音质标识、播放模式、桌面歌词显示、音量”。音质标识占固定槽位但在未知或不适用时保持空白，其他控件不得因歌词可见性、锁定状态或标识出现而位移或重排。
- 底栏采用左侧曲目信息、中央核心播放控制、右侧辅助控制的三段布局；桌面宽度下左右使用对称弹性轨道，使核心控制不受标题长度或辅助按钮数量影响并保持视觉居中。
- 播放模式按钮打开向上的四项菜单并明确标记当前模式，不再依赖逐次点击轮换。切换命令不得重建当前 Rodio source；只取消尚未开始的预载项并按新模式准备后续曲目。
- 当前播放列表在侧栏显示独立于导航选中态的播放中标识。标识采用三个小均衡器条，只动画 `transform` 和 `opacity`，不以定时 React state 更新整行；`prefers-reduced-motion` 下显示静态标识。

#### 音质文本标识

- 音质分类由 Rust 元数据边界产生类型化 DTO，React 只渲染结果，不按扩展名或字符串自行推断。每首只显示一个标识，优先级为 `Hi-Res > SQ > HQ`；未知元数据、无法判定或低于阈值时不显示。
- `Hi-Res`：可确定为无损的 WAV/FLAC，采样率不低于 88.2 kHz 且有效位深不低于 24 bit；使用克制的金色。
- `SQ`：其余可确定为无损的 WAV/FLAC；使用青绿/翡翠色，以区别于金色 Hi-Res。
- `HQ`：已知码率不低于 256 kbps 的 MP3；使用蓝青色。低码率 MP3 不给予品质承诺式标识。
- 使用固定 viewBox 的 SVG 文字描边框，不使用波形、图片或其他装饰图形；`HI-RES` 与 `SQ/HQ` 分别调整字面尺寸，使三档视觉留白均匀，并保持统一外框、明暗主题对比度和无障碍文本。标识是媒体详情的展示能力，不改变播放解码、输出采样率或文件格式支持范围。

#### 默认列表与曲目选择

- 默认列表和用户播放列表复用同一详情页、工具栏、曲目行、删除、清空、排序与外部导入能力。唯一差异是默认列表不写入 SQLite、应用正常退出后清空，并且不能被删除或重命名。
- 因默认列表当前只保存路径快照，实施前为其项目补充稳定的会话项目 ID；选择、范围选择、批量删除、排序和右键目标均以项目 ID 而不是数组下标或路径文本为标识。
- 单击选择一项；`Ctrl` 单击切换该项；`Shift` 单击以选择锚点建立连续范围；单击列表空白处清除选择；双击才激活该播放列表并从目标曲目播放。右键点击未选中项时先改为只选中该项，再打开菜单。
- 列表主体禁止文本选择，不实现容易与排序冲突的拖动框选。曲目整行在超过移动阈值后负责同列表排序，拖动开始时收束为当前曲目单选；`Ctrl`/`Shift` 手势只用于选择，不启动排序。拖动期间扩大曲目间隔并显示插入线，不重新引入 HTML5 `draggable` 或 `dataTransfer`。
- 详情页右上角保留统一“添加”菜单和“删除选中项”，不放置含义重复的叉号清空按钮。删除选中项在空选择时禁用；清空列表通过空白区域右键菜单进入并需要确认。默认列表的清空只清除会话项目；用户列表的清空采用 SQLite 事务。删除整个用户列表移到侧栏悬停操作和右键菜单，默认列表不显示删除列表操作。
- 应用退出时不再把默认列表或当前播放路径恢复到下一会话；保留与播放列表内容无关的用户偏好。此项由 ADR 0019 取代 ADR 0018 的旧会话恢复表述。

#### 应用右键菜单

- 应用内容区统一拦截浏览器原生 `contextmenu`，由应用壳提供单一自定义菜单宿主；菜单操作仍通过现有类型化前端边界与 Tauri command 调用，不让菜单复制领域逻辑。
- 自定义菜单通过页面级 Portal 挂载并使用视口坐标定位，不得受页面入场动画或父容器 `transform` 偏移；侧栏播放列表菜单只显示“重命名 / 删除”纯文本，避免重复图标和冗长对象名称。
- 曲目菜单：播放、删除选中项、全选、取消选择。列表空白菜单：添加文件、添加文件夹、全选、清空列表。用户侧栏播放列表菜单：重命名、删除播放列表；默认列表菜单：清空默认列表。
- 完全禁用浏览器原生菜单不能破坏输入框的基本编辑。对可编辑文本提供剪切、复制、粘贴、全选菜单项，或在该目标保留等价的系统编辑行为；不可为实现自定义菜单而阻断键盘快捷键、焦点或无障碍行为。
- 暂不加入“在资源管理器中显示”等需要新增平台 adapter 的操作；此类功能在出现明确需求时再按平台边界设计。

#### 桌面歌词三分区工具栏

- 歌词窗口顶部改为固定三列网格 `minmax(0, 1fr) auto minmax(0, 1fr)`：左侧显示单行、可省略的当前媒体名称；中央为上一曲、播放/暂停、下一曲；右侧为设置、锁定/解锁、关闭。
- 锁定后继续采用 ADR 0012 的透明歌词 WebView 与小型 Win32 owned-tool helper 组合，不引入全局 hook、轮询、输入注入或第二个 helper WebView。helper 只显示解锁图标，并相对歌词窗口的中央控制区定位。
- 歌词文本、滚动和 hover 背景策略与工具栏布局解耦；工具栏调整不得重新引入黑色首帧、锁定后无法命中或歌词同步回归。
- 该条由 ADR 0019 修订 ADR 0013 中的顶部控件顺序和锁定态 helper 位置。

## 非范围

- 应用图标、NSIS/MSI、文件关联、SMTC 应用身份、托盘、代码签名和 Tauri updater。此处的音质 SVG 标识是应用 UI 组件，不属于发行图标设计。
- 标签编辑、媒体库、受管理文件夹、AAC/M4A、在线能力或 Linux 实现。
- 歌词、转换领域模型重构；媒体库、歌单来源和独立可编辑队列只在未来出现明确需求时另行设计。

## 验收

- Rust 单元/集成测试覆盖外部路径分类、批量插入位置、部分拒绝、列表间隔创建、事务失败和内部/外部拖放隔离。
- Rust 自动测试覆盖当前用户列表插入/移动/删除同步、非当前列表编辑隔离、内部序列插入和会话恢复到默认列表。
- 浏览器测试覆盖中英文、浅色/深色、1080×700、760×520、长中文/英文元数据、空值和完整播放器两个页签；控制台无 warning/error。
- 浏览器必须确认默认列表标题不是拖放目标、添加按钮不溢出、底栏按钮定位当前列表，以及暂停/继续前后普通主内容不重挂载或重新播放 `view-in` 动画。
- 自动测试覆盖默认/用户列表的稳定项目 ID、批量删除、清空、当前列表同步和退出后默认列表不恢复；用户列表事务失败不得部分删除。
- 浏览器测试覆盖鼠标单选、Ctrl 切换、Shift 范围、整行拖拽排序及插入反馈、双击播放、右键播放、右键目标选择、禁用删除状态、默认列表清空和用户列表侧栏删除；正文拖动不得选中文本，输入框编辑菜单与快捷键保持可用。
- 浏览器测试覆盖底栏固定槽位、三种音质标识及无标识、明暗主题对比度、播放中侧栏标识和减少动态效果；播放状态/进度刷新不得导致非播放区域重挂载或闪烁。
- 桌面歌词三分区工具栏在浏览器中验证文本截断、固定几何、明暗主题与锁定状态布局；真实 Windows 锁定、helper 命中和多显示器位置仍由项目所有者实机验证。
- 在可行范围内验证 Windows 125%/150% 缩放；原生外部文件拖入、命中手感和系统缩放最终由项目所有者实机确认。
- 用可控延迟模拟 seek command：Slider 点击/拖动释放后在旧快照到达期间不回跳；连续两次 seek 只保留最后目标；失败才回退并显示错误。
- 歌词行鼠标点击和键盘激活提交准确 `startMs`，活动行随后居中；桌面歌词拖动/锁定穿透行为不受影响。
- 设置、侧栏、播放信息、歌词和窄屏主内容没有可见的 WebView 原生滚动条；Mantine ScrollArea 支持滚轮、触控板、拖动滚块和键盘滚动，且无嵌套滚动冲突。
- Windows 原生验证主窗口宽屏/窄屏分别恢复位置、尺寸与最大化状态；覆盖主屏/副屏、100%/125%/150% DPI 和显示器断开后的可见区域修正。
