# 0.1.0-rc.1 Windows 发布候选收尾

- 状态：Implemented；遗留原生验收并入 rc.2
- 日期：2026-07-23

## 已实现

- npm、Cargo、Tauri 版本统一进入 RC；主窗口标题和公开文档收束。
- Tauri updater 与 GitHub Releases 原生清单：稳定/预览通道按完整 SemVer 选择，draft/标记不一致 Release 被忽略，下载/验签/取消/安装由官方 updater 完成。
- 单一 `main-merge-delivery.yml`：PR 只读 required validation；受保护 `main` 合并后轻量判定版本并由固定 SHA 的 Tauri 官方 Action 自动构建、签名和创建 prerelease/stable Release。
- Updater 私钥只由受保护 `release` Environment 注入；更新完整性签名与未来 Authenticode 发布者签名分离。
- 本地诊断日志只收集 Resona 自身模块，Info+、256 KiB/KeepOne，不上传、不记录完整媒体路径。
- 隐藏 WebView 暂停播放、歌词、压缩和依赖轮询，恢复可见时立即同步 Rust 权威状态。
- 英文/中文 README、Agent 入口、许可证生成、发布规则测试和性能审计完成。

## 发布门禁

- `npm test/build/licenses`、Rust format/test/Clippy、workflow lint、版本一致性与 NSIS release build。
- GitHub Release 必须包含同次构建的安装包、更新产物、`.sig` 和 `latest.json`；SemVer prerelease 字段是发布类型唯一来源。
- 不提供 tag push、`workflow_dispatch`、GitHub CLI 或自写更新清单旁路；未改版本的 main 合并不重复发布。
- 安装包不携带 FFmpeg/ffprobe；测试工具和本地一次性签名密钥不进入仓库或正式产物。

## 并入 rc.2 的验收

- 用正式托管 Release 与受保护密钥完成一次真实覆盖更新。
- 多显示器/DPI、资源管理器拖入、桌面歌词、任务栏/SMTC、托盘、睡眠/蓝牙恢复和安装/卸载残留。
- 正式 Authenticode 发布者方案。

这些项目由 [rc.2 计划](0.1.0-rc.2.md) 和 [0.1.0 门禁](0.1.0.md) 继续追踪；本文件不再积累逐次 CI 调试流水。
