# 0.1.0-rc.1 Windows 发布候选收尾

- 状态：Accepted
- 日期：2026-07-23
- 前置条件：0.0.19 已完成并通过项目所有者 Windows 安装版验收

## 目标

在功能界面和 Windows 集成冻结的基础上，完成首个公开候选版所需的更新、签名、诊断、性能和发布链路；集中修复发行阻塞缺陷，不新增播放器能力。

原计划中的 0.0.20“更新器与发行加固”完整归并到本阶段，版本序列调整为 `0.0.19 -> 0.1.0-rc.1 -> 0.1.0`。

## 范围

### 更新与发布链

- 开始实现时把 npm、Cargo 和 Tauri 配置中的版本统一切换为 `0.1.0-rc.1`；RC 安装包、更新清单、运行时“关于”和发行说明必须读取同一版本事实。
- 使用 Tauri 官方 updater 实现设置“关于”中的主动检查更新、版本/说明/大小展示、下载进度、用户取消和安装前确认。
- 使用 GitHub Releases 托管 NSIS 更新产物和静态更新清单；无网络、清单损坏、签名错误或下载失败不得影响本地播放。
- GitHub Actions 只生成一个 Windows x64 NSIS 安装包及其 updater 签名、更新清单、版本说明和校验文件，不维护单独的替换程序或第二个安装渠道；Action 固定完整 commit SHA，使用最小权限。
- updater 签名私钥不得进入仓库、安装包或日志；公钥进入应用配置。Windows Authenticode 与 Tauri updater 使用独立信任边界。
- 从已安装的 0.0.19 验证覆盖升级，确认数据库、播放列表、窗口状态、歌词偏好、退出偏好和按需 FFmpeg 状态保持。

### 发行加固

- 建立本地、有限大小、可轮转和可清理的诊断日志，覆盖启动、播放初始化、SMTC、任务栏、托盘、更新和退出失败；默认不上传，不记录无必要的完整媒体路径。
- 测量冷/暖启动、空闲、播放、隐藏到托盘、桌面歌词和音频压缩扫描/转换时的 CPU、内存和进程状态；只优化有测量证据的回归。
- 完成许可证、GPL 源码义务、FFmpeg notice、安装包内容、版本说明和 SHA-256 审计。
- 修复候选版测试中发现的 P0/P1 和明确影响日常使用的缺陷；视觉调整仅限一致性、可读性、溢出和明显重绘问题。

### 原生发行矩阵

- 复核 `KNOWN_ISSUES.md` 中仍开放的资源管理器拖入、主窗口/桌面歌词多显示器恢复和 100%/125%/150% DPI 场景。
- 覆盖 Windows 10/11、浅色/深色/高对比度、Explorer 重启、任务栏自动隐藏、睡眠恢复、第二实例和文件关联。
- 验证干净安装、0.0.19 覆盖升级、同版本修复安装、卸载清理和用户音频保留。

## 非范围

- 新播放格式、标签编辑、媒体库、在线歌词、账户、遥测、强制更新、后台静默下载或远程配置。
- MSI、Microsoft Store、ARM64、32 位 Windows、开机启动、Jump List、Toast、全局快捷键或 Linux 实现。
- 第二套播放引擎、便携版自动更新渠道或未经 ADR 的生命周期变化。

## 自动验收

- 更新器覆盖有更新、已是最新、无网络、无效清单、签名错误、下载失败、取消和安装确认。
- TypeScript/Vite build、许可证生成、Rust format/test、Clippy `-D warnings`、Windows 分发审计、NSIS Release 和原生主窗口可见性门禁通过。
- CI 在干净检出中可重复生成与本地发布结构一致的产物，且不泄露私钥或把 FFmpeg/ffprobe 打入安装包。
- 日志轮转、路径隐私、退出清理、升级保留数据和失败降级有与风险相称的自动测试。

## 项目所有者验收

- 从 0.0.19 安装版执行一次真实更新，确认下载、确认安装、重启和状态保留。
- 完成仍开放的多显示器、DPI、原生拖入和桌面歌词发行矩阵；记录 Windows 版本、缩放、显示器布局与结果。
- 在干净 Windows 用户下抽查安装、开始菜单启动、文件关联、SMTC、任务栏、托盘、退出和卸载。
- 确认候选版界面无新增功能、明显重绘、不可达操作或发布阻塞视觉问题。

## 预计需要项目所有者介入

- 首次生成并离线备份 Tauri updater 私钥，将发布所需私钥配置为 GitHub Actions secret；仓库只保存公钥。
- 决定公开 RC 是否使用 Authenticode 证书或可信云签名，并提供相应发布凭据。未完成前只能生成明确标记的未签名候选测试包。
- 安装并验收一次由 GitHub Release 托管的真实更新；在此之前本地模拟更新不能替代端到端结论。

## 完成定义

- `0.1.0-rc.1` 安装包、更新产物、更新清单、版本说明、许可证通知和 SHA-256 相互一致且可重复生成。
- 没有未关闭的 P0/P1 发行缺陷；所有暂缓问题均有明确影响、复现条件和公开说明。
- updater 私钥不在仓库、日志或发布包中，断网时播放器核心完整可用。
- 项目所有者完成候选版验收后，进入 0.1.0 正式发布门禁，不再增加产品功能。
