# 0.3.0-beta.2 开发与验证

范围：修复 Linux 更新后需手动重启，以及 KDE Wayland 歌词启动选屏、跨屏与位置记忆；检查 Windows 对应实现。beta.1 已发布，本版尚未发布。

## 根因与改动

- Linux 安装成功原本只设置 complete，没有重启调用。现复核数据库成功后先复用退出前保存，再调用 Tauri request_restart；Exit 事件先释放 single-instance D-Bus 名称。下载/事务预览/Polkit 仍由用户触发，取消或安装失败不走重启分支。
- Wayland 旧几何只有 x/y/width，输出来自创建时主窗口；隐藏主窗口可被 GTK 按 (0,0) 误判至副屏。GTK 3 Wayland 后端未实现 primary monitor 查询，is_primary 全为 false 是该接口限制；KDE 的输出优先级仍存在。layer-shell 使用专用输出和边距，KWin 普通窗口记忆不接管。
- 新几何增加可选 output（厂商、型号、布局原点），先精确匹配，再匹配唯一同型号；无旧记录/原屏缺失时回退到已映射主窗口或可用屏。旧 x/y/width 可以读取，不迁移其他用户数据。拖动以 surface-local 指针推导布局位置，指针进入另一输出后重绑定歌词/helper 并约束尺寸。跨屏 remap 结束本次拖动，松手后继续调整；不新增全局鼠标能力，不实现运行中的热拔插恢复。
- Windows 原有系统拖动不钳制单屏，物理位置/宽度恢复按最大交集或最近工作区选屏，使用目标 DPI 后再恢复原点；没有发现 Linux 的同类算法问题。检查另发现持有服务锁调用 Tauri 拖动/几何查询可能与 DPI/resize 回调互等，现复制句柄后释放锁，锁定前定位后复核资源代次；字号更新仅保留已有无锁置顶/helper 同步。

## 验收边界

- 所有者确认 Windows 实机更新正常（2026-10-29），无需重复索要该项确认。
- Linux：真实应用内跨版本下载→验签→Polkit/Pacman→自动重启仍待安装版验证；本机重启测试仅证明重启机制和单实例释放。真实鼠标从副屏拖至主屏、松手继续定位、重启保留屏幕待所有者确认。
- Windows：待 CI 编译/原有几何与 helper 测试；实机只需双向跨屏（含负坐标和不同缩放）、关闭歌词再开/重启位置恢复、目标屏锁定解锁、字号变化及拖动时无卡死。代码检查不能代替真实 DPI 消息时序。
- 本轮不发布、不修改系统安装或 KWin 脚本。
