# 0.0.16 WAV 到 FLAC 音频压缩

- 状态：Completed
- 日期：2026-07-20
- 接受依据：项目所有者要求连续推进至 0.0.16，并确认压缩档位、位深和源文件删除规则

## 范围

- 固定 FFmpeg/ffprobe sidecar，仅接受 PCM WAV，输出 FLAC。
- 三档为“快速、平衡、最小体积”，只改变编码速度/体积，不宣称音质差异。
- 16-bit 和 24-bit WAV 保持原位深；32-bit integer/float WAV 显式量化为 24-bit FLAC。
- 所有档位保持源采样率和声道布局，不做重采样。
- 提供单/批量任务、进度、取消、冲突策略、临时文件、成功原子落盘和失败清理；默认不覆盖现有输出。
- “成功后删除源 WAV”默认开启并可关闭；开启时每批任务开始前必须弹出破坏性确认并明确删除数量。只有输出校验并原子提交后才能删除源文件，任何取消/失败/冲突均保留源文件。
- ffprobe 校验输出 codec、sample rate、channels 和 `bits_per_raw_sample` 后才提交结果。

## 验证

- 覆盖 16/24/32-bit、44.1/48/96/192 kHz fixture，三档参数、取消、冲突、损坏输入和临时文件清理。
- 比较解码后采样参数；32-bit 输入验证输出为 24-bit，其他输入位深保持。
- 验证删除开关默认值、确认门槛、成功后删除、失败/取消保留和删除失败报告。
- 完成许可证、sidecar 校验值、离线运行和 Windows Release 验证后，在 0.0.17 前暂停。
