# 0.0.12 播放列表与媒体库交互闭环

- 状态：Implemented，待项目所有者 Windows 实机验收
- 前置版本：0.0.11 Windows 应用生命周期与桌面歌词交互闭环
- 所属阶段：P3 本地媒体库
- 目标平台：Windows；Linux 仅保留结构，不在本阶段验证
- 提案日期：2026-07-19
- 接受日期：2026-07-19

## 背景

0.0.7 和 0.0.8 已完成 SQLite、播放列表、最近播放、受管理文件夹、直属目录扫描和 `lofty-rs` 只读元数据基础。项目所有者确认这些基础功能可运行，但指出播放列表保存/创建流程以及受管理文件夹内容入口当前不可用或反直觉。本阶段先完成可工作的功能闭环，不提前确定最终视觉和完整拖放交互。

## 阶段目标

让用户能够在现有应用壳中完成以下最小流程：查看和选择播放列表、从列表加载或播放曲目、查看受管理文件夹扫描出的直属音频、直接播放或加入当前队列，并在刷新或重启后保持数据一致。Rust 服务和 SQLite 继续是唯一权威来源。

## 实施范围

### 1. 稳定跨边界契约

- 梳理播放列表、播放列表项目、受管理文件夹和媒体记录的 DTO、ID、排序字段、缺失状态和 revision。
- 补齐 UI 需要的查询/刷新边界；command handler 只做输入验证和服务调用，不承载集合业务逻辑。
- 让播放列表操作使用明确的 `append`、`insert_at`、`remove`、`move` 语义，为后续拖放 UI 保留位置契约，但不在本阶段定稿拖放视觉。

### 2. 播放列表最小可用流程

- 显示默认播放列表和已保存列表，支持选择列表并读取其曲目。
- 支持从已保存列表加载到当前队列、播放单曲、追加到队列和移除列表项目。
- 保留已有创建、保存、重命名和删除能力；只修复完成流程所需的状态反馈、失败恢复和数据刷新，不重做最终交互。
- 对曲目顺序使用稳定的后端位置语义；按钮追加默认使用末尾，拖放排序的最终控件形式后置。

### 3. 受管理文件夹内容流程

- 受管理文件夹行可选择并展示扫描出的直属 MP3/WAV/FLAC 媒体记录。
- 支持手动刷新/重新扫描、加载中、空目录、缺失文件和单文件错误状态。
- 支持从媒体记录直接播放、追加到当前队列，并复用既有文件夹浏览和播放命令。
- 不引入递归扫描、全盘索引或实时文件监听。

### 4. 测试与错误隔离

- Rust persistence/service 测试覆盖列表项目增删改序、缺失文件、重复扫描和刷新后的 revision。
- command 契约测试覆盖无效 ID、失效路径、空集合和并发刷新失败。
- 前端构建和浏览器检查覆盖加载/空/错误/成功状态、中文/英文、浅色/深色和窄屏不溢出。
- Windows 实机只验收基本浏览、选择、播放、追加和重启持久化；不以截图评判最终视觉。

## 不包含

- 播放列表最终信息架构、拖放手势和视觉重构；待项目所有者进一步确认。
- 元数据编辑、封面编辑、实时文件监听、全盘扫描和在线服务。
- WAV/AIFF 到 FLAC 转换执行、转换队列和 FFmpeg UI。
- 桌面歌词最终字体、动画、位置持久化和多显示器拓扑恢复。
- AAC/M4A 扩展、Linux/Wayland/PipeWire 实现和验证。

## 验收标准

1. 用户可以打开默认/已保存播放列表，读取曲目并播放、加载或追加，不需要依赖页面刷新恢复状态。
2. 用户可以创建、保存、重命名、删除列表，并在应用重启后看到一致的曲目顺序。
3. 用户可以选择受管理文件夹并看到直属扫描结果，能刷新、播放和追加媒体记录。
4. 缺失文件、空目录、损坏媒体和无效集合 ID 都有可诊断错误或明确空状态，不静默吞错。
5. 既有播放 actor、输出设备、SMTC、歌词和桌面歌词生命周期不回归。
6. Rust 自动测试、前端构建、Clippy、许可证检查、Release 构建和 Windows 基本功能验收通过。

## 暂待确认

- 播放列表创建/保存的最终入口和层级。
- 播放列表内部拖入文件的视觉反馈和插入指示线。
- 受管理文件夹与文件夹浏览器、媒体库详情区的最终组合方式。

这些决定不阻塞本阶段的领域契约和最小功能实现；未经确认不把临时 UI 交互宣称为最终设计。

## 实现与自动验证结果

- persistence adapter 新增播放列表项目删除和重排，所有变更保持稠密位置并更新列表时间；未知列表/项目返回稳定错误码。
- Tauri 新增 `remove_playlist_item`、`move_playlist_item` 和 `replace_queue_and_play` commands；播放列表项目可按指定索引生成队列并开始播放。
- 播放列表页新增选中详情、重命名、载入、追加当前队列、移除和上下移动的最小功能控件；点击列表不再立即覆盖当前队列。
- 受管理文件夹可选中并展示已索引媒体记录，显示标题、艺术家、专辑、时长、封面存在性和 missing 状态；支持直接播放与追加队列。
- 浏览器 preview 补齐集合和 `append_to_queue` 模拟，验证英文/中文、浅色/深色、重命名、重排、移除、媒体追加以及 680x440/360x640 无横向溢出；控制台无 warning/error。
- 自动验证通过：29 个普通 Rust tests、8 个真实默认音频设备 tests、TypeScript/Vite build、许可证报告、Rust format、Clippy、`git diff --check` 和 Windows Release 构建/启动检查。

真实 Windows 的文件选择、SQLite 重启持久化、播放列表命令联动和受管理文件夹扫描结果交由项目所有者集中验收。
