# 0.0.20 更新器与发行加固

- 状态：Proposed
- 日期：2026-07-21
- 前置条件：0.0.19 完成；项目所有者确认更新托管位置与签名密钥保管方式

## 目标

接入可控、可失败降级的 Tauri 官方更新流程，并完成 0.1.0 候选版本的安装、升级、性能、许可证和故障诊断回归。

## 范围

- 使用 Tauri 官方 updater plugin 实现用户主动“检查更新”、结果提示、下载进度和安装前确认。
- 确定更新清单/安装包托管位置、稳定更新端点和离线行为；无网络或服务失败不能影响本地播放。
- 生成 updater 签名密钥，私钥不得提交仓库；记录备份、轮换和 CI/本地发布注入方式。
- 从一个已安装旧版本验证升级到候选版本，确认 SQLite migration、设置、播放列表、窗口状态和歌词偏好保持。
- 完成启动时间、空闲 CPU/内存、播放期间资源、辅助窗口和音频压缩扫描/转换的最终审计；只对有测量证据的问题优化。
- 审查崩溃/启动错误和本地诊断日志，确保无遥测、无敏感路径意外上传、无静默吞错。
- 完成依赖许可证、GPL 源码义务、FFmpeg notice、安装包内容和发布说明审查。

## 非范围

- 强制更新、后台静默下载、账户、遥测、远程配置或运行时许可证激活。
- 新播放格式、新工具、标签编辑、媒体库、在线歌词或 Linux 实现。

## 验收

- 更新可用、已是最新、无网络、签名错误、下载失败、用户取消和安装成功路径均有可诊断结果。
- 干净安装、旧版升级、卸载、文件关联、SMTC、托盘/退出、外部打开和桌面歌词完成 Windows 回归。
- 自动检查全部通过；真实设备测试和原生交互验收清单有明确结果，不以浏览器模拟替代 Windows Shell 行为。
- 候选安装包、更新产物、版本说明、许可证通知和 SHA-256 可由记录步骤重复生成。

## 完成定义

- 0.1.0 发布候选没有未关闭的发行阻塞缺陷；所有暂缓问题均有清晰影响、复现条件和公开说明。
- updater 私钥不在仓库、日志或发布包中，断网环境可完整使用播放器核心功能。
