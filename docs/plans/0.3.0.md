# 0.3.0：Arch Linux / Wayland 初始兼容

- 状态：Development Complete（`0.3.0-alpha.1` 本机开发预览）；待所有者实机验收，不是正式发行。
- 日期：2026-10-25
- 授权：所有者要求开发下一版本，开始兼容本机 Linux，当前只支持 Arch Linux 与 Wayland。
- 基线：当前 `dev` 的 `0.2.1`；该版本尚未合并/正式发布的历史交付状态不在本轮改写。
- 实现边界：[ADR 0028](../decisions/0028-arch-linux-wayland-baseline.md)、[ADR 0029](../decisions/0029-wayland-lyrics-and-mpris.md)；运行方法：[Linux 指南](../LINUX.md)。
- 下一交付阶段：[跨平台预览构建、AUR 与更新方案](0.3.0-preview-delivery.md)，方案已接受并实现，按 ADR 0031 使用每版本一个 tag/Release，待 main 发布/AUR 配置/Windows 覆盖更新验收；维持 `0.3.0-alpha.1`，不把本机开发完成等同于安装分发完成。

## 本轮交付

1. 版本统一为 `0.3.0-alpha.1`；Windows NSIS / 签名配置按平台隔离，Linux 可构建嵌入前端的原生二进制。
2. 保留播放、列表、CUE、封面和普通歌词；Linux 使用系统 FFmpeg，有缺失提示和重新检查入口。
3. Wayland 不执行全局窗口坐标 API；普通窗口保留尺寸和布局。桌面歌词使用 layer-shell overlay 保证置顶、锁定穿透与原生解锁，更新显示手动更新。
4. 托盘失败不阻止启动；无可用托盘时拒绝隐藏。Linux 原子提交不覆盖竞争产生的输出文件。
5. KDE MPRIS 发布封面、曲目信息、位置和动作，接收媒体控制、音量、循环/随机、Raise/Quit；共用权威播放 actor。
6. 增加 Arch 容器 PR 验证，与 Windows 结果共同构成原有 `PR validation` 门禁；正式发行仍仅走既有 main 工作流。

## 本机验证记录

- CachyOS x86_64、Wayland、KDE Plasma；GTK 3.24.52、WebKitGTK 2.54.2、ALSA 1.2.16.1、PipeWire ALSA 1.6.10。
- 53 项前端测试、生产构建通过；Rust 常规回归 108 项通过（另有 9 项设备/工具用例单独运行），Clippy 无警告。
- 单独串行运行的 9 项全部通过：默认设备枚举/打开、MP3、FLAC、192 kHz/32-bit WAV、错误后恢复、连续播放、播放模式切换、系统 FFmpeg 检查与 WAV→FLAC 格式矩阵。
- 初次回归发现一个仅适用于 Windows 分隔符的测试 fixture；已改为跨平台路径，数据库逻辑未改变。
- Tauri 本机开发/Release 构建通过；隔离 XDG 数据目录、`GDK_BACKEND=wayland` 原生启动未崩溃，日志记录服务初始化、前端 IPC 更新检查完成，主窗口尺寸保存成功；停止 Vite 后最终 Release 仍完成前端 IPC。正常 KDE 会话与无托盘宿主的临时 D-Bus 会话均初始化成功，无宿主路径记录可诊断降级。启动日志有 libayatana-appindicator 的弃用提示，来自 Tauri 的既有依赖，不影响本次启动。

- 浏览器验证宽屏 `1080×700` / `760×520`、窄屏 `420×720` / `360×600`，确认系统 FFmpeg 就绪/缺失提示和手动更新；复核中英文、明暗主题，稳定后无横向页面溢出。压缩窗口 `720×500` 的实色回退、控件可达性与空状态通过；无浏览器 error 日志。真实 DPI/多屏和原生视觉仍需验收。
- 原生 layer-shell 忽略测试通过，协议日志确认 overlay=3、无键盘交互、锁定空输入区域、GTK 解锁回调、字号高度 130/199px 和销毁重建。歌词浏览器补充覆盖 760×130 / 480×199（64px 极长行滚动），无横向页面溢出或 error。
- 最终 Release 的 `python3 scripts/test-linux-desktop.py` 回归通过，覆盖真实歌词前端首次 ready、关闭/重建及退出清理；曾暴露的隐藏 WebKitGTK 等待动画帧问题已修正，隐藏窗口仅做必要初始读取，不常驻轮询。
- MPRIS 的本机 D-Bus 实测覆盖元数据/封面和转义 URL、Play 幂等、PlayPause、Pause/Stop、前后曲、音量、SetPosition/过期 ID、负数 Seek、循环/随机、Raise/Quit。
- format、Clippy、许可证生成、品牌资源复现、actionlint 1.7.12 与 `git diff --check` 通过。后续 main Actions 已验证 Arch 包构建、安装/文件关联/卸载；当前门禁见 [STATUS](../STATUS.md)。

## 仍需所有者验收

- 实际听感、蓝牙断连/恢复、切换物理输出设备、睡眠恢复。
- 原生 GTK 文件选择、拖入、文件管理器定位、托盘菜单与关闭/退出，StatusNotifier host 重启。
- 歌词在真实鼠标下的拖动/左右调宽、锁定跨程序穿透、置顶与全屏遮挡、物理媒体键。当前只支持同一输出内移动，跨输出拖动和热拔插恢复未实现。
- 真实 Wayland 多显示器/缩放下的宽窄布局、尺寸/最大化恢复、首帧与明暗主题；浏览器结果只证明布局。
- Windows Release 原生回归；本机检查不能代替 Windows 实机。
- 普通版本 tag 的公开安装包待 main Actions；AUR 首次同步待配置，不以本地二进制视为已发布。

本轮不创建标签、不发布或覆盖安装应用、不合并 PR。
