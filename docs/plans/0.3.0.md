# 0.3.0 正式版开发计划

更新：2026-11-04。基线 main `8ebbe56`，沿用现有产品范围、Rust 权威状态、单一 Rodio 引擎及 PR CI/main CD。本轮已获授权持续实施、测试和必要合并；版本暂为 `0.3.0-rc.1`，发行门禁尚未解除。

## 实施结果

| 项目 | 已实施与验证边界 |
| --- | --- |
| U1/U2 提示统一 | Mantine 主题集中控制实体表面、明暗色、12px 字号、400/80ms 延迟、有界换行及 focus；`Hint` 收口空标签和弹层互斥。底栏、标题栏、列表、设置、压缩及歌词控件已迁移；窗口标题等非 DOM `title` 保留。音量只显示百分比，快捷键移至设置正文。详见 [ADR 0037](../decisions/0037-standard-tooltips.md)。 |
| F1 快照比较 | 比较完整输出格式和 CUE 字段；共享模型回归已验证旧实现失败、修复通过。 |
| F2 异步边界 | 事件注册经 bridge，处理注册失败/卸载；列表选择与摘要、播放及歌词轮询丢弃旧响应。真实 hook 的请求顺序回归覆盖过时成功/失败和命令后旧轮询。 |
| B1/B2 转换安全 | 并发排空 stderr，诊断限制 64 KiB；同目录排他临时文件由 RAII 清理，取消先终止并回收子进程再清理。成功提交前检查取消，既有输出不覆盖，源删除仍在提交后。新增大量诊断、失败清理及 Linux 活动进程取消回归。 |
| B3 列表协调 | 数据库写入、同步及读取后激活移至 MediaImportService 并串行化；提交后同步失败保留数据、执行序列转默认列表并报错，前端重读。覆盖并发编辑/激活、删除和同步失败重试。 |
| B4 互斥 | 清空扫描输入及 Windows 更新安装补齐既有文件任务门禁；服务互斥测试扩展，不依赖 UI 禁用。 |
| B5 持久化 | JSON 偏好和窗口几何共享同目录临时写入、sync、原子替换；关闭偏好写成功后才提交内存。回归覆盖完整替换、失败清理和重载重试；SQLite schema 未变。 |
| C1 清理 | 删除不可达 BrandWordmark 组件和无消费者的 simple-track 样式；保留安装器/README 使用的字标 SVG。未用 ffprobe 构造参数简化为 with_ffmpeg，保留依赖检查和真实矩阵。 |
| C2 所有权 | 设置视图及错误翻译移至明确所有者；不为文件长度继续拆组件或新增状态。 |
| 审查补充 | 输出设备恢复复用有界 seek，失败保留可诊断状态；歌词/CUE 解码前最多读取 8 MiB；Pacman 只读查询以临时文件接收 stderr，避免等待退出时管道填满，诊断读取有界。各项均有定向回归。 |
