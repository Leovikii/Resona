## 最小复核命令

在有 Node/npm、Rust/MSVC 的环境运行；常规命令不需要桌面交互：

```powershell
npm ci
npm test
npm run build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --manifest-path src-tauri/Cargo.toml --all-targets --locked
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --locked -- -D warnings
npm run licenses
git diff --exit-code -- docs/THIRD_PARTY_LICENSES.md
npm run build:exe
```

有真实输出设备/固定工具时按需补一次对应条件测试，不运行全部 `--ignored`：

```powershell
cargo test --manifest-path src-tauri/Cargo.toml focused_controls_preserve_paused_cue_position_on_real_output -- --ignored --test-threads=1
npm run prepare:test-tools
cargo test --manifest-path src-tauri/Cargo.toml pinned_ffmpeg_test_tools_preserve_matrix_and_quantize_32_bit_to_24 -- --ignored --test-threads=1
```
