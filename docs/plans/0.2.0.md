# 0.2.0 本地专辑播放增强

- 状态：In Progress
- 开始日期：2026-07-28

## 目标

- 同名 CUE 由 Rust 在导入阶段解析为有明确起止时间和元信息的逻辑音轨；播放列表、队列、定位、切歌和持久化均使用同一媒体源模型。
- 当前曲目封面按“内嵌封面、同目录 `cover` 图片、目录唯一图片、多图中的小尺寸方图”回退；目录扫描、源文件和解码尺寸保持有界，归一化结果继续共享给 React、SMTC 与任务栏。
- 桌面歌词极长单行只从头到尾线性滚动一次，进度与该行实际展示区间及播放位置同步；暂停、定位和减少动态效果均保持稳定。
- 播放列表曲目右侧显示时长，目录段和整表显示合计；CUE 展示逻辑分轨时长，摘要读取保持分批、有界且不解析封面。

## 实施与门禁

- CUE 支持 UTF-8、UTF-16 与 GBK 文本，解析失败不阻止原音频作为普通文件导入；同一物理文件的多个逻辑音轨不得被路径去重合并。
- SQLite 迁移必须保留 0.1.0 播放列表；普通文件的现有行为和旧播放会话格式保持兼容。
- 封面只扫描音频直属目录中的 JPEG/PNG，候选数量、文件字节、像素和缓存条目均有上限，候选排序必须确定。
- 自动验证覆盖 CUE 解析与区间、播放列表迁移、封面优先级/边界和歌词动画计算；通过前端测试与构建、Rust format/test/clippy、许可证和工作流检查。
- Windows 实机验收覆盖 CUE 连续切轨/定位、SMTC 与任务栏封面回退、桌面歌词暂停/定位和长句滚动。
