# 0.3.0-alpha.1：跨平台预览交付

状态：Accepted；按所有者反馈简化发布规则，版本保持 `0.3.0-alpha.1`。[ADR 0031](../decisions/0031-version-release-tags.md) 取代 ADR 0030 的同版本重复构建发布规则。

## 版本与发布入口

- tag 为 `v0.3.0-alpha.1`，标题为 `Resona 0.3.0-alpha.1`；每个应用版本只有一个 Release。
- 预发行 SemVer 使用 pre-release，稳定版使用普通 Release；预览不接管 latest 稳定入口。
- 仍由 `main-merge-delivery.yml` 在 main push 验证并发布；dev push 与 PR 只开发/验证，不发布。main 由所有者手动合并。
- 当前版本尚无普通版本 tag 时，main 中的交付代码改动可首次发包；已有 tag 时同版本合并跳过发布。下一次发布递增应用 SemVer。
- 运行序号、重试序号和 SHA 仅保留在构建元数据和关于页作追溯，不进入 tag、Release 标题或安装包名称，也不参与更新比较。
- 发布说明只读 `docs/releases/<version>.md` 的极简英文 Markdown；GitHub Release 与签名清单使用同一文本，不生成提交列表。

## 资产与完整性

| 资产 | 用途 |
| --- | --- |
| `Resona_0.3.0-alpha.1_windows_x86_64-setup.exe` / `.sig` | Windows NSIS / Tauri 安装包签名 |
| `latest.json` / `.sig` | Windows 更新清单 / 清单签名 |
| `Resona_0.3.0-alpha.1_arch_x86_64.tar.gz` | AUR 使用的预编译载荷 |
| `resona-preview-bin-0.3.0alpha1-1-x86_64.pkg.tar.zst` | pacman 原生安装包 |
| `PKGBUILD` / `SRCINFO` | 公开配方；GitHub 上传会改写点文件名，因此公开副本不带点 |
| `build.json` / `arch-packages.txt` | 构建身份与 Arch 依赖版本 |
| `Resona_0.3.0-alpha.1_source.tar.gz` / `LICENSE` / `THIRD_PARTY_LICENSES.md` | 对应源码与许可证 |
| `SHA256SUMS` | 所有公开资产摘要 |

两平台必须来自同一 SHA。发布任务校验构建身份、Arch 载荷摘要与 Windows 签名后创建草稿，上传并逐名校验全部资产，最后公开。已有公开版本禁止覆盖；旧的同 tag 草稿可清理后重试。上传/校验失败清理草稿，日志保留诊断；最终公开请求状态不确定时不删除可能已公开的 Release。

## 安装与更新

Windows 使用 NSIS，保留文件关联和 Tauri 签名更新；仅发现更高 SemVer，同版本或仅 metadata 改动不算更新。安装请求绑定检查时的 tag、版本、URL 与签名。稳定用户默认不接收预览。安装器尚无 Authenticode，README 披露 SmartScreen 提示。

Linux 只支持 Arch x86_64 / Wayland，使用系统依赖与 FFmpeg。预览 AUR 包为 `resona-preview-bin`，未来稳定包为 `resona-bin`，两包互斥；`pkgver` 将 alpha/beta/rc 映射为 Arch 顺序，`pkgrel=1`。升级应用版本时生成新包，不再每次合并递增包修订。安装注册桌面入口、图标和 MP3/WAV/FLAC 打开方式，不修改用户默认播放器。

Linux 应用不发现/下载安装更新，不执行命令或提权。关于页提供 `yay -Syu` / `paru -Syu` 复制和 AUR/Release 入口；手动包通过 `pacman -U` 安装新包。不提供 AppImage。旧本机测试包数据不会自动覆盖正常 XDG 数据，首次安装前应保留测试包目录。

## AUR 配置

首次 AUR 同步尚未完成；README 明示状态并提供原生包替代安装方式。确认包名与维护权限后，配置：

- 仓库变量 `RESONA_AUR_ENABLED=true`；默认关闭。
- 只允许 main 使用的 `aur` Environment。
- Environment secret `RESONA_AUR_SSH_KEY`：对应 AUR 仓库部署密钥。
- Environment variable `RESONA_AUR_KNOWN_HOSTS`：经可信渠道核对的 AUR SSH 主机公钥。

AUR job 只在完整 Release 公开后执行；下载固定 URL 验摘要，再用 `vercmp` 拒绝降级。相同版本配方必须逐字一致，不 force push。失败只重跑失败 job，不重新创建公开 Release。

## 验证与门禁

自动验证版本/tag 去重、预览隔离、Arch 版本顺序/配方、签名与篡改拒绝、双平台资产一致性、草稿失败清理、AUR 幂等与拒绝降级。Actions 执行 Windows/Arch 检查、签名安装器构建与干净 Arch 容器安装/文件关联/卸载。

本机产物仅测试，不提交或上传。Windows 原生覆盖安装/取消/签名错误/卸载仍需 Windows 实机；AUR 首次同步需所有者配置。真实桌面歌词、MPRIS、多屏/DPI 验收见 [Linux 指南](../LINUX.md)，容器结果不能替代硬件验收。
