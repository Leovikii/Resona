NFS actor 专项用 `RESONA_TEST_NFS_LOCATIONS` 设置 JSON URI 数组，运行 `selected_nfs_audio_decodes_seeks_and_plays -- --ignored --test-threads=1`。真实目录/文件名仅放本机临时环境，不提交仓库。桌面脚本可用 `RESONA_TEST_NFS_PATHS` JSON 物理路径数组追加低音量的第二实例、暂停/定位/继续和冷桌面打开验证；需要先用 KIO-FUSE 官方接口取得有效映射，勿从 busctl 的人类可读转义文本拼路径。

## 发现与取舍

本机 KIO-FUSE 父目录枚举返回空，并会使原可读子文件报 ENOTDIR。仅在空结果后补回目标不能解决后续播放失败。因此通过 GIO 挂载元数据识别 `fuse.kio-fuse`，先刷新映射并避免枚举；明确选择文件仍可播放。该规则涵盖同目录列表、自动同名 CUE、伴随歌词、外置封面和递归导入，不按 `/run/user/...` 目录名猜测。内嵌封面以及本地/内核挂载目录继续支持。

锁定 Tauri dialog/rfd 包装会丢弃无法转换为本地路径的 URI、未设置 Linux parent，且某些服务错误与取消混淆。最终使用同一锁定 ashpd 直接调用标准 portal，保留 URI/错误及 parent，未引入自制 chooser、Dolphin 子进程或桌面配置改写。歌词伴随文件扫描也必须遵守同一目录能力保护，否则前端刷新会再次破坏映射；NFS 专项现包含元数据/歌词读取后继续解码播放。portal feature 激活 zbus Tokio 后曾导致 MPRIS 缺少 reactor，已在线程进入现有 Tauri runtime 上下文，保留 GLib executor，并重跑桌面集成。

## 仍需验收

- Windows 本轮 MSVC/CI 与原生操作见 [Windows 交接](0.3.0-beta.1-windows-validation.md)，完成前不合并发布。
- 整个界面变英文仍未复现，不声明修复；需要故障时语言偏好、navigator/页面语言和启动环境。未修改语言初始化。

- KIO-FUSE 递归文件夹导入与自动 CUE/伴随歌词/外置封面发现有意禁用；网络转换的硬链接原子提交取决于文件系统，未放宽失败保护。
