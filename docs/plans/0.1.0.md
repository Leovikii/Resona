# 0.1.0 Windows 首个正式版发行门禁

- 状态：In Progress；功能稳定化实机验收通过，最终视觉收尾与发行门禁执行中
- 日期：2026-07-21，修订于 2026-07-26
- 前置条件：已满足；0.1.0-rc.4 为 Completed，且当前没有未关闭的发行阻塞缺陷

## 发行原则

0.1.0 是 Windows-only 的首个正式版，只发布 [PRODUCT.md](../PRODUCT.md) 已定义并经过验证的纯播放器能力。该阶段不新增功能，只允许修复发行阻塞缺陷、完善发布材料和重跑验收。

## 最终稳定化范围

- 音频压缩窗口按 Rust 权威批次状态区分当前任务与旧工作区。关闭旧工作区时恢复完整初始状态；进行中的转换不受窗口关闭影响，窗口保持关闭时在任务完成后清理，完成前重开则继续展示完整任务。
- 桌面歌词使用事件驱动的 Windows 原生 topmost 校正，覆盖显示、锁定、解锁、失焦、系统恢复与 DPI 变化；不使用定时置顶、全局 hook 或输入注入。
- 原生解锁 helper 保留无 WebView 架构，使用系统矢量图标字体和与桌面歌词工具按钮一致的命中、圆角与状态层级，不新增 UI 或图形依赖。
- 修复完整播放器歌词自动定位的祖先滚动：只滚动歌词 viewport，活动歌词不使用会制造横向溢出的位移效果。
- 右键菜单统一使用 Mantine `Menu.ContextMenu` 和“图标 + 简短文本”；批量关闭其他用户列表由 Rust/SQLite 单事务执行，并继续遵守活动列表删除后转移到默认列表的规则。
- 修复播放列表文件夹导入只读取直接子项的问题：Rust 递归扫描全部子目录且不跟随链接类路径；列表以可折叠目录段保留导入结构，顶层默认展开、子目录默认折叠，同时保持扁平曲目顺序为唯一播放顺序。
- 播放列表可见行以轻量元数据摘要显示“音轨号 + 标题”，标题缺失时回退去扩展名文件名并删除重复路径副标题；曲目右键菜单增加统一文件信息弹窗，按需展示标签、格式、码率、音频属性和路径，并经 Tauri opener 在系统文件管理器中定位文件。
- 播放列表目录展开状态按列表在当前会话内记忆。底栏恢复最右播放列表按钮，显式点击时返回权威当前列表、展开当前歌曲祖先目录并定位该行；自然切歌不改变目录或滚动状态。宽/窄底栏播放 ActionIcon 统一保持 `xl` 尺寸，紧凑音质角标均放在曲目信息区的时间右侧，核心三键相对整个底栏严格居中。窄屏下音量/播放模式左对齐，桌面歌词/当前播放列表右对齐。辅助按钮在正常、激活和禁用状态下均使用透明背景，hover/focus 与持久激活只改变 SVG 颜色；中央播放/暂停使用 Mantine 原生圆形实体背景、阴影 token 和白色实心图标，禁用时保留灰色实体轮廓。按钮按下态统一通过 Mantine 主题级 `activeClassName` 降低亮度，不使用根节点位移或缩放，保证绝对定位按钮和 Menu/Popover 锚点稳定。
- 上述功能已通过自动门禁和当前 Release EXE Windows 实机验收。剩余界面细节不作为新的功能轮次单独扩展，与 Resona 字标、单字母图标和音频格式角标合并为正式版最后一轮视觉收尾；正式版本号只在视觉方案和全部发行门禁关闭后统一切换。

## 必须满足

- 宽/窄屏播放列表外部拖入、完整播放器分页与信息排版、统一弹窗动效和压缩树首层展开已经冻结并通过验收。
- MP3、PCM WAV、FLAC 播放，播放列表/内部执行序列、播放模式、SMTC、LRC/SRT/VTT、桌面歌词和 WAV 到 FLAC 音频压缩通过回归。
- 0.1.0-rc.2 删除最近播放后，数据库升级只移除明确放弃的历史表并完整保留用户播放列表；rc.3 的 SMTC 封面、垂直音量控件和压缩窗口关闭清理，以及 rc.4 的窄屏拖放、播放器分页和压缩树展开通过回归。
- Windows 安装、卸载、文件关联、应用身份、既定托盘/退出语义和主动更新通过干净环境测试。
- 无已知数据损坏、源文件误删、无法退出、无法启动、播放核心失效或更新签名错误等 P0/P1 缺陷。
- 版本号、安装包、更新清单、源代码标签、GPL/第三方通知、发行说明和 SHA-256 相互一致。
- 明确公开 32-bit FLAC、不稳定系统文件选择器等仍存在的限制，不把未验证能力写入发行说明。

## 明确不进入

- 标签编辑、媒体库、受管理文件夹、AAC/M4A、在线服务、WASAPI Exclusive、ASIO 和 Linux 实现。
- 为赶版本临时加入第二播放引擎、未经 ADR 的后台生命周期或无法离线运行的依赖。

## 发布后

- 0.1.x 只处理兼容性、可靠性和小范围体验问题；新增产品能力进入后续次版本计划。
- 根据实际错误报告和性能数据重新评估系统文件选择器、更多格式、标签编辑和 Linux Wayland/PipeWire 路线，不预先承诺日期。
