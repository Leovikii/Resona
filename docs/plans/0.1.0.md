# 0.1.0 Windows 首个正式版发行门禁

- 状态：Ready for owner release
- 日期：2026-07-21，最终修订于 2026-07-26

## 范围

0.1.0 是 Windows x64 首个正式版，只交付 [PRODUCT.md](../PRODUCT.md)
定义且已经验收的本地播放、播放列表、歌词、Windows 集成、WAV 到 FLAC
和安全更新能力。Linux 保留平台 adapter 边界，但本版本不发布 Linux 安装包。

## 已关闭门禁

- rc.1–rc.4 与正式版收口功能、自动回归、规定视口和 Windows 实机功能验收完成。
- 版本统一为 `0.1.0`；品牌 SVG、应用/文件图标、默认封面和 NSIS 位图可重复生成。
- 临时通知、播放器切歌渲染、窄屏默认页和最终交互样式已统一。
- GPL、第三方通知、发布说明、已知限制和 Windows 安装/更新边界已同步。
- 0.1.0 强制 Tauri updater 签名，不强制 Authenticode；未签名安装包的
  SmartScreen 提示、官方下载入口和 SHA-256 核对要求已公开说明。

## 所有者发布步骤

1. 在受保护的 GitHub `release` Environment 配置
   `RESONA_UPDATER_PUBLIC_KEY`、`TAURI_SIGNING_PRIVATE_KEY` 和可选密码。
2. 将版本变更经受保护 PR 合并到 `main`；单一交付工作流创建 `v0.1.0`
   stable Release、NSIS、updater 产物、`.sig` 和 `latest.json`。
3. 在 Release 页面公布安装包 SHA-256，并从正式渠道抽查下载、安装、启动、
   文件关联和一次应用内更新。

实际 GitHub Release 与覆盖更新验证完成后，本计划改为 `Completed`。
