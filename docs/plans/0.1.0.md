# 0.1.0 Windows 首个正式版发行门禁

- 状态：Proposed
- 日期：2026-07-21
- 前置条件：0.1.0-rc.3 为 Completed，且没有未关闭的发行阻塞缺陷

## 发行原则

0.1.0 是 Windows-only 的首个正式版，只发布 [PRODUCT.md](../PRODUCT.md) 已定义并经过验证的纯播放器能力。该阶段不新增功能，只允许修复发行阻塞缺陷、完善发布材料和重跑验收。

## 必须满足

- 播放列表外部拖入、完整播放器信息排版和项目所有者确认的最后 UI 批次已经冻结并通过验收。
- MP3、PCM WAV、FLAC 播放，播放列表/内部执行序列、播放模式、SMTC、LRC/SRT/VTT、桌面歌词和 WAV 到 FLAC 音频压缩通过回归。
- 0.1.0-rc.2 删除最近播放后，数据库升级只移除明确放弃的历史表并完整保留用户播放列表；rc.3 的 SMTC 封面、垂直音量控件和压缩窗口关闭清理通过回归。
- Windows 安装、卸载、文件关联、应用身份、既定托盘/退出语义和主动更新通过干净环境测试。
- 无已知数据损坏、源文件误删、无法退出、无法启动、播放核心失效或更新签名错误等 P0/P1 缺陷。
- 版本号、安装包、更新清单、源代码标签、GPL/第三方通知、发行说明和 SHA-256 相互一致。
- 明确公开 32-bit FLAC、不稳定系统文件选择器等仍存在的限制，不把未验证能力写入发行说明。

## 明确不进入

- 标签编辑、媒体库、受管理文件夹、AAC/M4A、在线服务、WASAPI Exclusive、ASIO 和 Linux 实现。
- 为赶版本临时加入第二播放引擎、未经 ADR 的后台生命周期或无法离线运行的依赖。

## 发布后

- 0.1.x 只处理兼容性、可靠性和小范围体验问题；新增产品能力进入后续次版本计划。
- 根据实际错误报告和性能数据重新评估系统文件选择器、更多格式、标签编辑和 Linux Wayland/PipeWire 路线，不预先承诺日期。

## 完成定义

- 正式安装包和更新产物已发布，源码标签、版本说明、许可证通知和 SHA-256 可公开核对。
- `docs/STATUS.md` 记录最终自动/实机验收结果与仍存在的已知限制，0.1.0 状态更新为 Completed。
- 发布后从安装渠道完成一次下载、安装、启动、检查更新和媒体文件打开抽查。
