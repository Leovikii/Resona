# 0.3.0-rc.1 范围与验收

修复 KDE Wayland 拖动普通窗口后，窄屏底边、宽屏右边沿轨迹留下持续闪烁线条，并增加柔和原生阴影。所有者已确认最终测试通过并授权 PR、发布及分支同步。

## 实现边界

- 共享 `shell_regions` 将模糊裁剪到 `[1, width - 1) × [1, height - 1)`；覆盖新旧协议、主/压缩窗口，过小窗口不提交非正尺寸矩形。
- 原生阴影使用固定 24px 八块黑色渐隐贴片，每个 surface 生命周期仅创建一份 9800 字节不可变共享内存池；最大化/全屏移除，还原复用缓冲区。要求 shadow manager / wl_shm v2，缺失时保留无阴影窗口。
- GTK unmap/unrealize 清理仅释放自有对象，map 重建并恢复正文矩形，不向已销毁 surface 发请求。GTK 保持 surface 提交权。
- 不修改窗口几何、输入区域、标题栏、Windows Mica 或歌词；无新增依赖、迁移、设置及重绘轮询。阴影不能替代 blur 边界修复。长期决定见 [ADR 0033](../decisions/0033-frameless-titlebar-and-kde-material.md)。

- fmt、嵌入前端 Clippy、TypeScript/Vite、Node Linux/交付/通道 21 项、许可证无差异及正式/隔离标识 Release 构建通过。
