# 0.1.0-rc.3 Windows 媒体呈现与控件收尾

- 状态：Completed；实现、自动回归与 Windows 实机功能验收完成
- 日期：2026-07-25
- 前置：rc.2 自动门禁完成；原生观察发现 SMTC 封面未生效

## 范围

- SMTC 不再接收不受 WinRT 支持的 `data:` URL。共享 `Artwork` 的编码字节按内容哈希投影到应用缓存文件，再以 `file://` 提交；切歌和退出清理旧文件，失败时依次回退应用占位图和纯文本。
- 底栏音量弹层改为垂直滑杆和紧凑百分比；弹层内滚轮每次增减 10 个百分点，范围保持 0–100%，拖动与键盘仍沿用 Mantine Slider。
- 420px 及以下的播放列表与宽屏保持一致：普通歌曲显示序号，当前歌曲在同一位置以动态播放指示替换序号。
- 关闭音频压缩窗口时丢弃扫描输入和列表；活动扫描会取消且旧结果不能写回，已经启动的转换继续由 Rust 服务管理。
- 压缩子窗口仅补充自身需要的显示与标题权限，保证关闭后可由主窗口重新显示，不扩展文件系统权限。

不引入新的媒体会话库、播放状态、压缩窗口生命周期服务或持久化数据。

## 验收

- 自动测试覆盖 SMTC 文件投影复用、WinRT 路径正规化、清理与压缩输入丢弃；TypeScript build、Rust test/format/Clippy 和差异检查已通过。
- 浏览器已验证宽/窄布局、明暗主题中的垂直音量弹层和窄屏播放状态列；Windows 开发版已验证滚轮单次双向精确变化 10 个百分点。
- 2026-07-25 项目所有者确认 Windows 实机功能测试正常：带封面、无封面及切歌后的 SMTC 卡片，关闭并重开压缩窗口的列表清理，以及窄屏序号/播放动画均通过验收。
