## 范围

- 用户播放列表与播放队列的指针拖动重排、外部拖放插入线、自动滚动、键盘/焦点和错误反馈。

- 歌词文字透明度、未锁定 hover 固定交互背景和两行滚动槽；seek/revision/reduced-motion 直接定位。
- 常用窗口尺寸、缩放、中英文、浅色/深色及长文本视觉收口。

- 纯函数位置约束、窗口状态持久化、拖放位置和 reduced-motion 回归。
- 浏览器只验证 Web 前端；Win32 穿透、原生 helper 与多显示器行为通过自动边界测试和最终人工清单记录。
