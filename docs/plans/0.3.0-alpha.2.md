## 核查与实现

| 反馈 | 根因与改动 | 已有证据与限制 |
| --- | --- | --- |
| KDE 亮暗主题不跟随 | Tao 0.35.3 的 `set_theme(None)` 在 Linux 写 GTK 浅色。adapter 改用 gio 读取 portal `color-scheme` 并订阅变更，分别保存桌面值和 auto/light/dark 偏好，GTK notify 校正 Tao 竞争写入。Windows 保留既有 Mica 路径 | 原生 GTK 测试用真实 portal proxy 的本地信号验证 light→dark→light、三种偏好和竞争写入；不修改用户桌面设置。真实桌面切换的完整 WebKit 视觉仍需观察 |
| KDE 切换器图标回退 | 开启 Tauri `enableGTKAppId`，GTK 初始化前设置同名 GLib process name；与 `io.github.vki.resona.desktop` 及 hicolor PNG 对齐 | GTK application ID 和实际 `xdg_toplevel.set_app_id` 已验证；安装版切换器图标仍需肉眼确认 |
| KDE 最大化/最小化无动画 | 应用身份不完整影响任务栏归组与动画目标；KWin squash 在 iconGeometry 为空时跳过。保留原生窗口角色/装饰，不模拟特效或改系统设置 | 本机 KWin 6.8.1 的 activeEffects 在主窗口/压缩窗口原生按钮操作时均观察到 maximize、squash 启动；系统快捷键/任务栏路径与动画观感仍需观察 |
| 歌词背景移开不恢复 | CSS hover 改为显式 pointerInside；pointer leave/cancel/锁定清理。Linux WebKit 原生 enter/leave 补齐 surface 进出，事件只发给歌词窗口 | 浏览器验证移入 38%→移出设置值 20%；原生事件桥及生命周期测试覆盖进入/离开信号传递。真实拖动/调宽后离开仍需鼠标验收 |
| 解锁图标移开消失 | Linux 保持 mapped/input surface，只切换 GTK 按钮 opacity；Windows 空闲不画字形，保留 alpha=1 命中并重置重显状态 | GTK 原生测试两次进入/离开后仍映射、不抢焦点、点击解锁与重建；Windows 增加自有 HWND 消息测试，检查 hover/leave/重显/点击和 alpha，交由 Windows CI |

歌词背景规则保持：空闲/锁定为用户值，未锁定交互为 `max(用户值, 38%)`。设置大于 38% 时移开不再变浅是预期，文字透明度独立。主窗口保留解锁入口；helper 外仍穿透。没有全局鼠标 hook、指针轮询、输入转发、额外 WebView 或播放引擎。

## GTK 与 mpvkit 对照

对照 `Leovikii/mpvkit` 的 `34d2e4f`：它也使用 Tauri / GTK / WebKitGTK；`linux_desktop.rs` 在 GTK 前设置 process name，并通过 gio portal 读取系统主题。其 MPV 播放窗口另有 Vulkan/Wayland 路径，不能据此把整个播放器换成直接 Wayland。Resona 继续沿用 GTK 的输入、窗口角色、WebKit 和 layer-shell 集成，只在既有 adapter 补齐 KDE 行为。

## 精简测试与结果

共享逻辑在 Windows CI 跑完整 Node 套件；Linux 只额外跑 POSIX/交付 Node 用例。Rust、Clippy 和本机编译仍分别执行，因为两个平台的原生实现不同。Linux FFmpeg 两次 cargo 调用合并为一次；窗口切换从 24 次缩为 4 次（两次完整往返），保留尺寸记忆、并发 resize、最大化恢复和重建。安全、迁移、取消与转换矩阵不删除。

| 层次 | 本轮验证 |
| --- | --- |
| 自动逻辑 | Node 63 项、Linux Rust 119 项常规测试通过，11 项原生/设备用例默认忽略；新增 Windows helper 消息测试由 Windows job 执行 |
| 原生 KDE | 主题/GTK ID/主窗口与压缩窗口按钮、几何、KWin maximize/squash 特效启动；歌词 layer-shell/输入区域、原生离开通知、helper 显隐/解锁、字号/拖动命令、销毁重建 |
| 实际 Release | `scripts/test-linux-desktop.py` 通过：MP3/WAV/FLAC 桌面入口冷启动/已有实例转交、托盘歌词前端 ready/重建、MPRIS 元数据/封面/播放控制/定位/模式/激活/退出；Linux 启动不查更新 |
| 浏览器显示 | 四种主窗口尺寸、明暗主题、Linux solid 与 Windows Mica 预览、压缩 720×500、歌词常用与 64px，无横向溢出；歌词 pointer enter/leave 计算样式验证（20% 恢复、90% 保持及滑块键盘 End）。浏览器只证明共享显示与交互 |
| 构建门禁 | 前端生产构建、Linux Release、Rust format/Clippy、许可证/品牌产物、workflow 和差异检查；最终双平台结果以 PR 为准 |

按代表性组合覆盖主题/视口/材质，不做所有组合的重复截图；改动后只重跑受影响层。详细执行规则见 [DEVELOPMENT](../DEVELOPMENT.md)，原生命令见 [LINUX](../LINUX.md)。所有会话测试串行运行并使用新建的 XDG 数据/缓存目录，保留用户桌面字体配置。

## 仍需实机验收

- Windows 真实鼠标进入/离开/再次点击、歌词区域外点击/滚轮穿透、Mica/标题栏与系统主题、SMTC/托盘及安装覆盖。Linux 自动结果不能替代 Windows 原生桌面视觉。
- KDE 安装版切换器图标、标题栏双击/快捷键/任务栏的动画观感、真实拖动/调宽/cancel 后离开和 helper 区域外穿透；特效关闭时应服从桌面，不自行模拟。
- 两端 DPI/分数缩放、多屏、字体清晰度与实际鼠标手感。Linux 跨输出歌词拖动和热拔插恢复仍未实现；其他发行版、X11 和 ARM 不在本轮范围。
