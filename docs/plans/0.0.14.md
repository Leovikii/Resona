# 0.0.14 播放体验与完整播放页

- 状态：Completed
- 日期：2026-07-20
- 接受依据：项目所有者要求连续推进至 0.0.16，并明确播放列表/队列与 UI 状态规则

## 范围

- 落实 ADR 0015：单击曲目投影完整列表、底栏队列抽屉、单一标题/状态、渲染隔离。
- 修复冷启动首次双击仅创建 WebView2 进程但主窗口保持隐藏的问题；由 Tauri 页面加载完成事件负责显示窗口，前端显示调用只作兜底。
- Rust 权威播放模式：顺序、单曲循环、列表循环和随机。
- 安全恢复队列、当前曲目、位置、音量、输出选择和播放模式；启动保持暂停/停止，不自动发声。
- 底栏封面/展开按钮打开覆盖主内容区的完整播放页，关闭后恢复原视图。
- 使用 Lofty 按需读取当前曲目标题、艺术家、专辑、封面和音频参数；损坏标签不阻止播放。
- 完整播放页只覆盖侧边栏右侧的主内容区并保留底栏；左侧显示封面和曲名，右侧默认显示歌词，可切换到播放信息（采样率、位深、码率、声道、歌手、专辑与源文件）；不建立媒体库或封面索引。

## 验证

- 播放模式边界、恢复数据迁移、损坏/缺失文件降级和恢复后不自动播放。
- Release 冷启动首次双击即可显示窗口；重复启动仍只聚焦同一个主窗口。
- 浏览器验证标题/状态唯一性、队列抽屉、覆盖页、中英文、明暗模式和进度更新隔离。
- Rust 普通/真实设备测试、Clippy、许可证与 Windows Release。
