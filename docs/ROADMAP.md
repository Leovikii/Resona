# 路线图

路线图表达交付顺序，不承诺日期。当前事实见 [STATUS.md](STATUS.md)，产品边界见
[PRODUCT.md](PRODUCT.md)。

## 0.1.0

首个 Windows x64 正式版已完成开发、自动回归和实机功能验收，当前等待项目所有者
通过受保护的 `main` 交付链发布。它包含本地 MP3/WAV/FLAC 播放、播放列表、歌词、
桌面歌词、Windows SMTC/任务栏/托盘、文件关联、WAV 到 FLAC、NSIS 和签名更新。

计划：[0.1.0 发行门禁](plans/0.1.0.md)

## 0.1.x 候选

0.1.0 发布并获得真实反馈后，才评估兼容性、可靠性、键盘/多显示器细节和有基准依据
的性能改进。标签编辑、额外格式等产品能力不得以补丁版本扩大范围。

## Future Linux

Linux 复用领域层和 React UI，替换系统媒体会话、窗口、输出设备、托盘、打包与更新
adapter。开始前需单独确定发行格式、GPG/仓库签名策略和原生验收环境；Windows
Authenticode 不进入该构建边界。
