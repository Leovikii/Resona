# 路线图

路线图表达交付顺序，不承诺日期。当前状态以 [STATUS.md](STATUS.md) 为准。

## P1 增量策略

为控制风险和返工，P1 不作为单次大版本开发：

| 版本 | 范围 | 状态 |
| --- | --- | --- |
| 0.0.1 | Tauri/Rodio 最小 WAV/FLAC 播放链 | 已验收 |
| 0.0.2 | MP3、固定 fixture、进度/时长、定位、音量、结构化错误 | 已验收 |
| 0.0.3 | 队列、连续切歌、混合采样率与 Gapless | 规划 |
| 0.0.4 | 设备枚举、默认设备变化、蓝牙断开与恢复 | 规划 |

AAC/M4A 可行性验证不阻塞上述增量；在 0.0.4 之后依据实际需求单独决定。P1 完成后再进入 P2 应用壳和正式 UI，不在播放契约未稳定时提前扩展界面。

## P0 项目基础

- 技术栈与许可证确定
- 文档、ADR、进度台账和目录边界
- Tauri 2 + React + Mantine 初始化
- lint、format、test、build 基线
- 依赖许可证检查

验收：新环境可按文档完成安装、测试和构建，基础窗口可启动。

## P1 播放技术验证

- 锁定 Rodio/CPAL/Symphonia 稳定版本和最小 feature 集
- 专用 audio actor、typed command channel 和权威状态事件
- MP3、PCM WAV、FLAC 播放、暂停、定位和队列
- 44.1/16 至 192/24 的 fixture 与混合采样率队列
- Gapless、曲目结束、错误日志和坏文件隔离
- WASAPI Shared 的默认/指定设备枚举
- 板载声卡、蓝牙断开、默认设备变化和休眠恢复
- AAC/M4A 低成本可行性验证

验收：必选格式和采样规格稳定播放，定位与连续切歌可靠；设备变化可恢复或进入明确错误状态，音频线程不阻塞 Tauri/UI。

## P2 应用壳与播放体验

- 主窗口、导航和主题
- 当前播放、队列和播放控制
- 键盘操作、窗口状态和设置
- 长列表虚拟化

验收：完整本地播放流程可在常用缩放下稳定使用。

## P3 本地媒体库

- 目录管理、增量扫描和文件监听
- lofty-rs 元数据与封面读取
- SQLite schema、migration 和搜索
- 专辑、艺术家和曲目视图

验收：大型媒体库可增量更新，坏文件不阻断扫描。

## P4 歌词

- LRC 解析和同步
- 独立桌面歌词窗口
- 透明、置顶、锁定穿透、解锁移动
- 多显示器与 DPI 状态保存

验收：桌面歌词随播放稳定同步，锁定和恢复行为可靠。

## P5 元数据与转换

- 元数据编辑可行性评估及实现
- FFmpeg 转换队列、进度和取消
- WAV/AIFF 到 FLAC
- 元数据、封面、冲突和临时文件处理

验收：转换不覆盖源文件，失败不留下被误认为成功的输出。

## P6 Windows 发布

- 安装、升级和卸载
- FFmpeg sidecar、Rust crates 和第三方许可证与通知
- 崩溃和诊断日志
- 性能、可访问性和回归验证

验收：发布包可在干净 Windows 环境离线安装和运行。

## Future Linux

在 Windows 版本稳定后评估 Wayland + PipeWire。该阶段开始前重新确认 Tauri/WebKitGTK、透明窗口、输入穿透、全局快捷键和分发策略。
