# 路线图

路线图表达交付顺序，不承诺日期。当前事实见 [STATUS.md](STATUS.md)，0.1.0 范围见 [PRODUCT.md](PRODUCT.md)。

## 已完成基础

0.0.x 已完成 Rodio 播放、输出设备、用户/默认播放列表、本地歌词、桌面歌词、完整播放器、WAV 到 FLAC、宽/窄屏布局、Windows SMTC/任务栏/托盘、NSIS、文件关联、按需 FFmpeg 和应用生命周期。仍有效的长期约束保存在 [ADR](decisions/README.md)，不再保留逐版本实施流水。

## 0.1.0-rc.1

功能开发完成：Tauri updater、GitHub Releases/Actions、签名边界、诊断日志、资源审计、公开仓库文档和自动发布门禁已落地。

遗留验收并入 rc.2：真实 GitHub 覆盖更新、多显示器/DPI、资源管理器拖入、桌面歌词、睡眠/蓝牙恢复和真实安装身份。

## 0.1.0-rc.2

计划：[0.1.0-rc.2](plans/0.1.0-rc.2.md)

- 删除最近播放 UI、后端写入与数据库表
- 底栏、完整播放器、SMTC、托盘和任务栏共享有界封面缓存
- DWM 缩略图/实时预览只显示封面或占位图

- 保留 FFmpeg，移除 ffprobe 转换热路径并使用有界文件级并行
- 文件行逐项进度，输入/输出总体积和节省空间汇总
- 清理失效文档并完成 rc.1 遗留 Windows 发行矩阵

## 0.1.0

计划：[0.1.0 发行门禁](plans/0.1.0.md)

rc.2 完成且没有发行阻塞缺陷后才能发布。正式版不新增能力，只允许修复阻塞问题、完成 Authenticode/更新验收、生成一致的安装包、更新产物、版本说明、许可证和校验值。

## 0.1.x 候选

只有 0.1.0 发布并取得真实反馈后才重新评估：

- 标签编辑
- AIFF 或额外无损格式
- 更完整的可访问性、键盘导航和多显示器细节
- 由基准证明必要的播放/大目录性能优化

这些项目不得提前扩大 0.1.0 范围。

## Future Linux

Linux 复用领域层和 React UI，仅替换系统媒体会话、窗口行为、输出设备展示、托盘、打包与更新 adapter。开始前必须单独建立计划并确认发行格式、依赖和原生验收环境。
