## 0.0.13 实现结果

详见 [0.0.13 播放器范围收束与列表信息架构计划](plans/0.0.13.md)。数据库收缩、临时默认列表、external-open、新侧栏和启动首帧已实现并通过自动检查；原生外部打开、拖放和启动闪烁感知待项目所有者验收。

项目所有者验收重点：

- 旧数据库迁移后用户播放列表和最近播放保持，媒体索引表安全删除。
- 默认列表不持久化；同目录路径快照相同只切换目标，目录变化才原子更新。
- 第二实例或命令行打开媒体复用现有进程，不创建第二套播放核心。
- 侧栏按“最近播放、分隔、播放列表标题/新增、默认、用户列表、工具/设置”工作。
- 主窗口默认尺寸合理，冷启动和主题恢复无明显白屏闪烁。

## 后续阶段边界

### 0.0.14 播放体验

- 顺序、单曲循环、列表循环和随机播放模式
- 音量、输出设备、当前队列和播放位置的安全恢复；启动保持暂停
- 底部播放器展开的覆盖式完整播放页
- 当前文件的按需元数据、音频参数、封面和歌词

### 0.0.15 交互与视觉

- 已有曲目和用户播放列表的内部拖动重排
- 完善 0.0.13 外部文件插入与间隔创建的命中范围、插入线、自动滚动和失败反馈
- 最终播放列表创建、重命名、删除和错误反馈
- 中英文、浅色/深色、常用 DPI/缩放、键盘和无障碍回归
- 桌面歌词位置/尺寸恢复和显示器变化后的可见区域约束
- 桌面歌词文字透明度、未锁定 hover 固定交互背景和两行滚动切换；减少动态效果时直接定位

### 0.0.16 音频压缩

- 只支持 PCM WAV 到 FLAC
- FFmpeg sidecar 固定版本、来源、构建选项、许可证和校验值
- 队列、进度、取消、冲突处理、临时输出、验证和失败清理
- 默认开启“验证成功后删除源 WAV”，但每批必须破坏性确认且可关闭；不覆盖已有 FLAC，不把有损来源标记为无损提升

### 0.0.17 界面与压缩工作区

- 工具页收束为入口；音频压缩迁入单实例普通工作窗口，完成文件/文件夹拖入、递归扫描、目录树、去重、警告和扫描取消
- 完整播放器改为右侧主内容互斥视图，修正不透明表面、底栏接缝、歌词文案和侧栏退出行为
- 外部拖放期间扩大侧栏列表间隔和曲目插入间隔，保持激活态与插入反馈稳定

### 0.0.18 交互与 UI 冻结

- 修复外部文件拖到用户播放列表行、曲目间隔和侧栏列表间隔时的追加、按位置插入与新建列表
- 严格隔离内部曲目重排与外部文件导入，提供部分拒绝和失败分类反馈
- 集中收口完整播放器详情文本层级、长文本策略和项目所有者补充的 UI 细节
- 完成中英文、浅色/深色、常用尺寸、长文本和 Windows 缩放回归后冻结功能 UI

### 0.0.19 Windows 分发与身份

- 先用 ADR 确定托盘与关闭语义，再实现托盘
- NSIS 离线安装、MP3/WAV/FLAC 文件关联和第二实例参数转发
- 正式应用身份、SMTC 名称、最终图标、快捷方式、manifest 和许可证通知
- 安装、升级保留数据、卸载和干净 Windows 验证

### 0.0.20 更新与发布加固

- Tauri updater 主动检查、用户确认更新、失败降级；无强制更新、后台静默下载或遥测
- 更新托管、签名私钥保管、旧版升级和断网运行验证
- 启动、空闲、播放、桌面歌词和音频压缩性能审计
- 许可证、GPL 源码义务、本地诊断、安装包内容和完整原生回归

### 0.1.0 发行门禁

- 0.0.18-0.0.20 均完成且没有发行阻塞缺陷后才能发布
- 只允许缺陷修复和发布材料调整，不再增加产品能力
- 产物、更新清单、源码标签、许可证通知、版本说明和 SHA-256 必须一致

## 明确不进入 0.1.0

- 受管理文件夹、媒体库数据库、搜索、专辑/艺术家聚合和实时监听
- 标签编辑、AAC/M4A、AIFF 压缩和长尾格式
- 在线歌词、在线元数据、账户、云同步和遥测
- WASAPI Exclusive、ASIO、DSP、可视化和视频
- Linux/Wayland/PipeWire 实现与验证

## Future Linux

Windows 0.1.0 稳定后评估 Wayland + PipeWire。开始前重新确认 Tauri/WebKitGTK、透明窗口、输入穿透、系统媒体会话和分发策略；通用 UI 只消费 capability，不假设 Windows 原生 helper 可以照搬。
