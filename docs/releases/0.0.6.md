# Resona 0.0.6

Date: 2026-07-18
Status: Completed; SMTC display identity deferred

## Delivered

- Added the isolated Windows `MediaSessionAdapter` using `souvlaki 0.8.3`.
- Registered SMTC after the main window's first usable window event, with a bounded initialization retry and graceful fallback when the native handle is unavailable.
- Added playback, pause, toggle, stop, next, previous, seek-by, and set-position event mapping through typed adapter commands.
- Published filename, duration, playback state, and low-frequency position updates to Windows SMTC.
- Set the Windows AppUserModelID to `io.github.vki.resona` so unbundled Release builds are identified by name instead of “Unknown app”.
- Configured Release builds as a Windows GUI subsystem application; Debug development runs retain the terminal for diagnostics.
- Kept the UI and Rodio playback contract unchanged; Windows handles and souvlaki types terminate inside the platform adapter.
