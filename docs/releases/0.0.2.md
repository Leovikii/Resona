# Resona 0.0.2 播放能力闭环

日期：2026-07-17

## 目标

在 0.0.1 “可以发声”的基础上，覆盖 MP3、固定 WAV/FLAC/MP3 fixture、进度/时长、定位、音量和结构化错误，同时保持单窗口最小验证界面。

## 已实现

- MP3、WAV、FLAC 文件选择与 Rodio 解码。
- 音频 actor 的权威进度、总时长、定位和音量状态。
- 暂停/继续/停止、自然结束和错误恢复。
- Tauri 错误返回稳定 `code` 与 `message`。
- 39 个可再生成的音频格式与边界样本，包含 SHA256 清单。
- 依赖许可证报告生成器和 Windows CI 配置。

## 已知限制

32-bit FLAC 明确不支持。导入该文件时，当前曲目停止，播放器进入带 `decode` 错误的失败状态；应用不会崩溃，随后选择 MP3、WAV 或 16/24-bit FLAC 可以恢复播放。WAV 32-bit integer/float 正常。
