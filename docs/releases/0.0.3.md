# Resona 0.0.3 队列与连续播放

日期：2026-07-17

## 已实现

- Rust 权威队列，稳定队列项 ID、状态、时长和错误信息。
- 多选文件替换默认播放列表，按钮追加到队列底部。
- 队列项播放、移除、清空、下一曲和按目标索引排序。
- 单一 Rodio `Player` 和输出设备，预载下一首 lossless 曲目。
- 使用 Rodio 公开的 `source::Done` 原子结束标记，不在音频线程发送应用 channel。
- WAV、FLAC、MP3 混合队列和坏文件隔离。
- 最小队列界面，包含列表项状态、内部拖拽排序和传输控制。
- Windows 文件选择对话框采用单实例互斥，避免快速重复点击叠加原生模态窗口。
- 32-bit FLAC 明确作为不支持格式处理，失败后可继续播放有效曲目。

## 范围限制

当前版本不实现系统级文件拖放、文件夹浏览、用户播放列表持久化、最近播放、SQLite、设备切换、歌词、AAC/M4A 或 Linux。系统级拖放的插入位置协议已写入架构文档，留待正式应用壳阶段接入。

Windows 文件选择由 Tauri dialog 2.7.1 + rfd 0.16.0 调用系统 `IFileOpenDialog`，插件会自动设置主窗口为 parent。应用阻止同一窗口重复打开对话框；若单个系统对话框仍卡住，应优先检查 Windows Explorer、不可达网络位置和第三方 Shell 扩展，应用不设置无法安全取消原生 COM 对话框的伪超时。
