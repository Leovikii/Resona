# Resona 0.1.0-rc.1

首个公开候选版：加入 GitHub 原生稳定/预览更新检查、签名 NSIS 自更新和合并后自动发布链，并完成发布前性能、音质与仓库整理。

- 所有合法 SemVer prerelease（包括 alpha、beta、rc）统一进入 GitHub prerelease；预览通道仍会接收更高正式版。
- 隐藏 WebView 暂停播放、桌面歌词和压缩状态轮询，恢复可见时立即同步 Rust 权威状态。
- 新增本地有限轮转诊断日志；不上传、不记录媒体完整路径，卸载时随应用数据清理。
- 根 README 面向用户，中文入口与开发文档分离；Mantine 完整参考保留为本机忽略文件，不进入 Git 仓库。
