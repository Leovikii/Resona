状态：Validated（2026-07-18）

## 交付内容

- SQLite schema version 2，兼容已有 0.0.7 数据库并记录封面存在性。
- 受管理文件夹添加、移除、列出和手动扫描。
- 直属目录增量索引 MP3/WAV/FLAC；子目录和不支持格式不进入本阶段索引。

- 单文件解析失败不阻断同一文件夹其余文件；缺失记录保留诊断状态。
- 文件夹页面增加最小管理入口，播放列表交互保持不变。

## 项目所有者验收

项目所有者已确认 0.0.8 功能正常。验收范围如下：

1. 在“文件夹”页添加一个实际音频目录。
2. 执行扫描，确认文件夹状态变为“扫描完成”，应用保持可操作。
3. 再次扫描，确认仍能正常完成且没有重复的受管理文件夹条目。
4. 使用包含子目录、非音频文件或损坏音频的目录扫描，确认单个文件不会使整个扫描失败或阻塞应用。
5. 移除受管理文件夹，确认该文件夹条目消失，但磁盘上的原目录和音频不受影响。
6. 确认现有播放、播放列表和最近播放行为没有回归。

媒体记录详情和 `missing` 状态尚未在 0.0.8 的最小 UI 中展示；索引幂等、直属目录过滤和缺失记录保留已由 Rust 自动测试覆盖，不列为本次 UI 实机验收的可见结果。

验收后项目所有者进一步确认：受管理文件夹当前只能添加、扫描和移除，不能选择、展开或浏览其索引内容，因此 0.0.8 仅代表扫描与索引基础设施通过验证，不代表媒体库交互已经可用。该交互与播放列表交互统一推迟设计；现有数据库、扫描和元数据 adapter 可直接复用。
