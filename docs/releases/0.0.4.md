# Resona 0.0.4

Date: 2026-07-17
Status: Completed

## Delivered

- Added CPAL output-device enumeration with stable device IDs, names, default-device markers, and interface type.
- Added system-default and fixed-device selection through the typed playback engine contract.
- Added output stream error reporting and actor-owned recovery. The player preserves queue, volume, pause state, and approximate position when the selected output becomes available again.
- Kept WASAPI in shared mode. Sample-rate negotiation, resampling, Bluetooth routing, and bit depth remain owned by the operating system output path.
- Replaced the custom end-of-track source wrapper with Rodio's public `source::Done` primitive.
- Added a minimal output selector and refresh action to the UI.
- Kept the Windows file dialog single-flight guard and structured failure state. No JavaScript timeout was added because a native modal dialog cannot be safely cancelled from the WebView.

## Limits

- No WASAPI Exclusive, ASIO, bit-perfect, or manual sample-rate controls.
- No Linux implementation or validation in this release.
- No AAC/M4A support added; the supported import set remains MP3, WAV, and FLAC with 32-bit FLAC explicitly rejected.
