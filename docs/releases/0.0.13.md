# 0.0.13 实现与验收记录

日期：2026-07-20

状态：Implemented，待项目所有者 Windows 实机验收

## 交付内容

- 删除受管理文件夹、媒体索引数据库和对应前后端运行时代码，保留用户播放列表与最近历史。
- schema v3 为播放列表增加稠密位置并把最近历史限制为 100；v2 migration 保持列表、项目顺序和最近历史。
- 新增 Rust 会话内临时默认列表；打开单个 MP3/WAV/FLAC 时枚举同目录直属音频，相同路径快照不发布新 revision。
- 初次命令行参数、第二实例参数和应用内文件选择统一进入 `open_media_context`。
- 侧栏改为最近播放、播放列表标题/新增、默认、用户列表以及底部工具/设置；移除文件夹和侧栏正在播放页。
- 支持用户列表创建、重命名、删除、添加、插入、移除、重排，以及外部拖入侧栏间隔创建列表的 typed 边界。
- 主窗口改为 1080×700、最小 760×520；同步主题预绘制后隐藏启动，React 首帧完成后显示。
- Release 验证脚本要求主窗口 HWND 实际可见，避免隐藏窗口被误判为启动成功。

## 项目所有者验收项

1. 冷启动、暖启动以及系统/浅色/深色恢复时无明显白色闪烁，默认和最小窗口尺寸可用。
2. 命令行启动和第二实例打开音频时复用现有进程，默认列表载入同目录直属音频并从目标开始播放。
3. 同目录再次打开只切换目标；增删文件后再次打开会更新默认列表。
4. 原生拖入用户列表、曲目间隔和侧栏播放列表间隔时，追加、插入与自动创建位置正确。
5. 重启后用户列表和最近历史保留，默认列表恢复为空。
6. 播放、进度、SMTC、歌词、桌面歌词、输出设备、主窗口退出与单实例无回归。
