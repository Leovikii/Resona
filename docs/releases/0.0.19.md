## 实现结果

- 即时切歌不再进入全局 busy；默认和用户播放列表使用最后一次请求胜出。
- SMTC 增加品牌封面，并与安装器快捷方式、文件关联和进程共享 `io.github.vki.resona` 身份；曲名读取 Rust 权威队列项，封面提交失败时会降级重试纯文本元数据。
- 任务栏缩略图提供上一曲、播放/暂停和下一曲；图标使用透明背景、最大化白色符号和细深灰外轮廓，复用 Windows 自带按钮底板，映射播放进度、暂停和失败状态，并处理 Explorer 重建。
- 托盘提供主窗口恢复、最多 10 个字符的紧凑曲目信息、播放控制、桌面歌词和完整退出；检查更新移入设置“关于”。
- 关闭主窗口默认询问退出或隐藏到托盘，支持“不再询问”和设置页三态持久偏好；活动扫描/压缩退出需二次确认。
- FFmpeg/ffprobe 不进入安装包；工具页以简洁文案提示按需下载，从固定 GitHub Release 资源取得依赖，提供进度、取消、完整性校验、安全解压和原子启用。
- 设置新增“关于”，显示当前版本、检查更新、GitHub 仓库入口和版权信息。
- MP3/WAV/FLAC 文件图标删除格式文字，只以蓝/金/紫主体色区分，并可通过跨平台的 `npm run icons:windows` 调用 Tauri 官方 CLI 重现生成。
- 桌面歌词首次初始化默认使用 `30px` 字号、`100%` 文字透明度和 `20%` 背景透明度；已有偏好不覆盖。
- NSIS 使用 `currentUser` 一键安装到 `%LOCALAPPDATA%\Programs\Resona`，注册 MP3/WAV/FLAC；非更新卸载清理 Resona 专属注册表和 AppData，绝不删除用户音频。
- 正式更新下载/安装归入 0.1.0-rc.1；已冻结 Tauri updater + GitHub Releases 静态清单、用户主动检查和 updater/Authenticode 双签名边界。
