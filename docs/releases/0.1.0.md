# Resona 0.1.0

Resona 0.1.0 is the first stable release of our local-first Windows audio player.

## Highlights

- Play local MP3, WAV and FLAC files with persistent playlists and multiple playback modes.
- View album artwork, track information and synchronized lyrics in the full player or desktop lyrics window.
- Control playback from Windows media controls, the taskbar and the system tray.
- Open supported audio files directly through Windows file associations.
- Convert WAV files to lossless FLAC with safe batch processing.
- Enjoy responsive wide and compact layouts with light, dark and system themes.
- Keep your listening private with no account, telemetry or cloud library.

## Download

Download the Windows x64 installer from the official GitHub release. Windows may show a SmartScreen prompt because the installer is not Authenticode-signed. In-app updates remain cryptographically signed.
