# Resona 0.1.0

Resona 0.1.0 is the first stable Windows release of the local-first audio player.

## Highlights

- Play local MP3, PCM WAV and FLAC files with persistent playlists, recursive folder organization and four playback modes.
- View embedded artwork, metadata and synchronized LRC/SRT/VTT lyrics in the full player or the event-driven desktop lyrics window.
- Control playback through Windows SMTC, the taskbar, tray and registered MP3/WAV/FLAC file associations.
- Convert supported PCM WAV files to FLAC with bounded parallel workers, validation before commit and optional source deletion only after success.
- Use the app entirely locally without an account, telemetry or a cloud media library; FFmpeg is downloaded only when the compression tool is explicitly enabled.
- Refined the 0.1.0 interface with stable wide/compact layouts, shared transient notifications, responsive playback controls and a unified high-contrast Resona icon system.

## Install and update

Download the Windows x64 NSIS installer attached to this release. The installer is not Authenticode-signed, so Windows may show a SmartScreen prompt; download only from the official GitHub release and verify the published SHA-256. In-app updates require the matching Tauri updater signature. Existing preview installations can be upgraded in place without removing playlists or preferences.

## Known limitations

- Windows x64 is the only supported distribution for 0.1.0.
- 32-bit integer and floating-point WAV input is intentionally quantized to 24-bit FLAC; playback of 32-bit FLAC is not supported.
- The native Windows file picker has a known low-frequency blocking issue without a stable reproduction.
- AAC/M4A, AIFF, a managed media library, tag editing, online services and Linux packages are outside the 0.1.0 scope.
