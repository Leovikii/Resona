## 完成范围

- Rust 导入同名 CUE 为带区间的逻辑音轨，贯穿播放、定位、切歌、列表与 SQLite 持久化；0.1.0 数据迁移和普通文件行为保持兼容。
- 封面按内嵌、同目录 `cover`、唯一图片、多图小尺寸方图回退；有界扫描与共享缓存继续供 React、SMTC 和任务栏使用。
- 曲目、目录段和整表展示 Rust 摘要/逻辑区间提供的时长；摘要按物理文件复用，不解析封面。
- 桌面极长歌词按行展示区间线性滚动一次，暂停/定位同步；Windows WinEvent 观察器合并外部窗口事件并无激活校正置顶，资源代次隔离迟到任务。

长期边界见 [ADR 0026](../decisions/0026-cue-logical-tracks-and-artwork-fallback.md)、[ADR 0013](../decisions/0013-windows-lifetime-and-desktop-lyrics-controls.md) 和[架构](../ARCHITECTURE.md)，不在计划中重复诊断和实现流水。
