## Changes

- Add Arch Linux support for x86_64 and Wayland.
- Add always-on-top desktop lyrics and KDE media controls.
- Improve system fonts, window controls and layout sizing.

## Install

- Windows: download the `.exe` installer. Unsigned by Authenticode; SmartScreen may prompt.
- Arch Linux: install `resona-preview-bin` from AUR when available, or use the `.pkg.tar.zst` package.
