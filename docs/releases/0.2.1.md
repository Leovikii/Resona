# Resona 0.2.1

状态：未发布，发行说明草稿。

## UI 优化

- 关闭询问精简为简短说明、“记住选择”和“隐藏到托盘 / 退出”；默认焦点落在安全动作上，处理请求期间防止重复提交，失败可重试。活动任务退出确认继续保留。
- 压缩时自动展开当前文件的祖先目录；多个运行项目共同展示活动分支。手动折叠在当前批次内优先，不自动滚动或抢焦点。
- 压缩窗口固定汇总栏增加整体处理进度和清晰终态，与主窗口工具入口采用同一计算口径。失败计入已处理但不计入成功体积，取消不强制填满进度。
- 转换结束后以醒目摘要显示结果、节省空间及实际源文件处理情况；完成按钮禁用，防止重复转换已处理批次。添加、移除或清空输入后可开始下一批。全部失败、取消、删除异常及体积增大均如实提示。
- 大目录保留增量展示，折叠目录及尚未显示的后续条目提示活动数量。总进度支持辅助技术和减少动态效果。

开发与验证结果见[0.2.1 验证记录](../plans/0.2.1-validation.md)，正式交付门禁见[版本计划](../plans/0.2.1.md)。
