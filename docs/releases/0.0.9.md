# Resona 0.0.9

状态：Completed（2026-07-19）

## 交付内容

- 自动发现音频同目录、共享基础 stem 的 `.lrc`、`.srt`、`.vtt`；支持 `song.vtt`、`song.flac.vtt`、`song.wav.vtt`、`song.zh-CN.vtt` 等限定名，多格式并存时依次优先 LRC、SRT、WebVTT。
- Rust `LyricsService` 负责文本解码、解析、统一时间行、缓存和当前行选择，不进入 Rodio 音频线程。
- 支持 UTF-8、UTF-8 BOM、UTF-16 BOM，以及 UTF-8 无效时的常见中文 GBK 回退。
- 支持 LRC 多时间戳、offset、标题/艺术家/专辑；支持 SRT/WebVTT 起止区间、多行 cue 和 WebVTT 纯文本化。
- 正在播放页显示同步歌词、平滑滚动、无歌词/空文件/读取/编码/解析失败状态。
- 同一歌词 revision 不重复跨 IPC 返回歌词全文；播放列表和受管理文件夹交互保持不变。
