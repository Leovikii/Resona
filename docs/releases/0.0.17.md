# Resona 0.0.17

- 日期：2026-07-20
- 状态：纠正性实现和自动验收完成，待项目所有者 Windows 原生交互验收

## 完成内容

- 完整播放器改为右侧主内容区互斥视图，侧栏切换直接退出播放器；修复透明感、底栏白边和“同步歌词”术语。
- 播放列表和曲目外部拖放期间扩大插入间隔；内部曲目/播放队列只保留拖拽排序，移除上下箭头，并用应用私有拖拽标记隔离外部导入热区。
- 主工具页收束为入口，新增单实例 `audio-compression` 普通 Tauri WebView、最小 capability 和窗口几何恢复。
- 新增 Rust 权威递归扫描工作区：多根路径、去重、链接/重解析点边界、进程内 `hound` WAV 头验证、取消、警告、目录树和排除操作；45 文件回归不依赖 ffprobe。
- 压缩档位、删除开关和转换命令移入顶部控制区，分层目录树独占剩余宽度；FFmpeg/ffprobe Windows 子进程统一隐藏控制台。
- 压缩窗口接入页面加载完成显示；桌面歌词接入透明 HTML 预绘制和首个权威快照就绪握手，消除黑窗、透明度和占位歌词闪烁。
- 完整播放器歌词自动居中且无横向滚动条；歌词/播放信息面板和切换栏尺寸固定，关闭按钮留出安全区。播放信息以单行分别展示输入文件参数和真实 Rodio/CPAL 输出流配置。
- 底栏桌面歌词锁定按钮和忙碌状态使用固定槽位；音量改为固定按钮弹出滑杆，状态变化不再挤压控件。
- LRC/SRT/WebVTT 统一采用音乐歌词持续显示语义：第一行开始前保持空白，之后在下一行开始前持续显示最近一行；SRT/VTT cue 结束和间奏不再让主播放器或桌面歌词消失。
- 底栏右侧改为五个 28px 等距槽位，播放队列固定在最右；删除重复展开按钮，完整播放器只通过左侧封面切换，并在 hover/focus 显示展开/收起图标。设置页八行统一为 44px 行高并收紧分组节奏。
