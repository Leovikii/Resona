# Resona 0.0.1 技术验证

日期：2026-07-17

## 目标

以最低实现成本证明 Tauri 2 + React + Mantine + Rust + Rodio 技术链可以在 Windows 上选择并播放本地 WAV 或 FLAC 文件。该版本不是可日常使用的播放器。

## 已实现

- 主窗口选择 `.wav` 或 `.flac` 文件。
- 播放、暂停、继续和停止。
- 播放自然结束后回到停止状态并释放当前播放器。
- Rodio 输出设备延迟打开，缺少音频设备时应用仍可启动并返回可诊断错误。
- Rust 播放 actor 独占输出对象，音频数据不经过 WebView/Tauri IPC。
- 前端轮询权威播放状态，显示失败原因。
