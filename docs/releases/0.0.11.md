# Resona 0.0.11

状态：Completed，项目所有者 Windows 功能验收通过（2026-07-19）

## 交付内容

- 桌面歌词窗口顶部控件：上一曲、播放/暂停、下一曲、设置、锁定/解锁、关闭。
- 设置按钮激活主窗口并切换到设置页；设置页提供歌词字号（16-64 px）、歌词颜色和背景透明度。
- 主界面底部播放控制区提供桌面歌词显示/隐藏和锁定/解锁入口，运行时操作不再放在设置页。
- 新增 Rust `previous_playback` 命令，上一曲与 Windows SMTC 使用同一队列语义：播放超过 3 秒先回到当前曲目开头，否则切换上一首有效曲目；位于第一首时重播当前曲目而不污染播放状态。
- 修复歌词时间轴空白区：Rust 保持 `active_line_index = None`，桌面歌词无活动行时不再回退显示第一行。
- 主窗口关闭时显式退出整个 Tauri 应用；桌面歌词不会继续维持播放核心。
- 接入 Tauri 官方 `tauri-plugin-single-instance 2.4.3`，重复启动只激活现有主窗口。
- 隐藏桌面歌词时停止其窗口资源并释放歌词 WebView/helper；再次显示按需重建。
- 原生 helper 使用 layered alpha，锁定空闲时使用近透明 alpha=1 保留命中，鼠标进入热点后显示解锁图标。

## 项目所有者验收

1. 启动并播放音频，从底部播放区显示桌面歌词；顶部控件顺序和中英文文案正确。
2. 测试上一曲、播放/暂停、下一曲、关闭、锁定/解锁；控件不会触发窗口拖动。
3. 点击设置按钮，确认主窗口显示并自动进入设置页；调整字号、颜色、背景透明度，确认桌面歌词实时或重新显示后生效。
4. 拖动进度条进入两条歌词之间的空白区，确认不显示第一行或旧行；进入下一 cue 后正确显示对应歌词。
5. 锁定后将鼠标移入原生 helper 热点，确认透明热点能首次显示解锁按钮并可点击；离开后按钮再次不可见。
6. 关闭主窗口，确认播放停止、桌面歌词和 helper 消失、没有残留 Resona 进程。
7. 连续启动两次 Resona，确认只存在一个应用实例和一份播放状态。
