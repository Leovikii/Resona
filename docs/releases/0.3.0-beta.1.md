# Resona 0.3.0-beta.1

- Open selected NFS audio through KDE KIO-FUSE without requiring directory enumeration.
- Use the KDE desktop portal for Linux file selection, including network locations.
- Import NFS folders recursively through native KIO directory listing, including companion CUE, lyrics and artwork.
- Reuse KIO directory sessions, accept readable network URIs, and prevent overlapping imports with visible scan status in playlists and compression.
- Simplify notifications with native Mantine styling.
- Follow native system UI languages.
- Add focused-window controls: Space to play/pause, Left/Right to seek 5 seconds, Up/Down to adjust volume by 10 percentage points, with visible volume feedback.

Temporary network mappings may require reselection after reconnecting or ending the desktop session.
