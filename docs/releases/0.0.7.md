# Resona 0.0.7

状态：Completed（2026-07-18）

## 交付内容

- 新增 Rust-owned SQLite persistence adapter 和 schema version 1 migration。
- 支持创建、保存当前队列、加载和删除用户播放列表。
- 支持最近播放记录、同路径去重、播放次数和直接重新播放。
- 新增持久化 Tauri command DTO 与 React library feature，页面包含空、加载和错误状态。
- 保留 Windows-first 范围和现有 Mantine 应用壳，不进行视觉重构。
