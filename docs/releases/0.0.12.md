# Resona 0.0.12

状态：Implemented，待项目所有者 Windows 实机验收（2026-07-19）

## 交付内容

- 播放列表项目新增事务化删除和重排，顺序始终归一为稠密位置；未知列表和项目返回稳定错误。
- 新增 `replace_queue_and_play`、`remove_playlist_item` 和 `move_playlist_item` Tauri commands。
- 播放列表页支持选择列表后查看项目、重命名、载入为当前队列、追加到当前队列、加入当前队列曲目、移除和上下移动。
- 单击已保存播放列表只显示详情，不再立即覆盖正在播放的队列。
- 受管理文件夹可选择并显示直属索引媒体，展示标题、艺术家、专辑、时长、封面存在性和 missing 状态。
- 媒体记录可直接播放或追加到当前队列；双击受管理文件夹仍可进入既有按需文件夹浏览。
- 浏览器 preview 增加播放列表、受管理媒体和队列追加状态，用于独立前端交互回归。

1. 新建播放列表并保存当前队列；关闭并重新启动 Resona，确认名称、项目和顺序保持。
2. 选择已保存列表，确认单击只展开详情；测试重命名、上下移动、移除、载入为当前队列和追加到当前队列。
3. 在列表详情中选择不同曲目播放，确认从该曲目开始消费所选播放列表顺序。
