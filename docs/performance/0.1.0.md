# 0.1.0 性能基线

2026-07-23 在 Windows x64 Release 构建上完成初始审计：

- 主窗口 10 次可见就绪中位数 `259.0 ms`，范围 `249.6–268.5 ms`。
- 稳定 60 秒的父进程空闲 CPU 约单核心 `0.026%`，Working Set 峰值
  `30.27 MiB`，Private Bytes 峰值 `5.96 MiB`。
- 隐藏 WebView 会暂停前端播放、歌词、压缩和依赖轮询，恢复可见后立即同步 Rust
  权威状态；Rust 播放与 Windows 原生投影不随 WebView 隐藏而暂停。
- 播放 actor 维持 `150 ms` tick，原生播放投影维持 `500 ms`；当前没有测量依据
  支持改变频率、加入虚拟化或复制 Rust 状态。

数据只覆盖当时的父进程启动与空闲场景，不能外推实际播放、WebView2 子进程、托盘或
桌面歌词资源占用。进一步优化必须先在目标场景建立同机基准。
