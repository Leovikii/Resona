# 已知问题

只记录仍开放、可复现或有明确重新调查条件的问题。已关闭缺陷不保留流水。

## KDE 与歌词交互验收

alpha.2 已修复主题覆盖、Wayland 应用 ID、歌词背景离开恢复和双平台 helper 空闲字形。KDE 原生回归已验证主题信号/手动覆盖、实际 app_id、主窗口与压缩窗口的 maximize/squash 特效启动，以及 GTK helper 显隐/点击恢复。

仍需实机观察：安装版切换器图标、系统快捷键/任务栏路径的动画观感、真实鼠标拖动/调宽后的离开和 helper 区域外穿透；Windows 原生 Mica、鼠标与 DPI 也须独立验收。浏览器和原生消息测试不能代替这些观察。[逐项记录](plans/0.3.0-alpha.2.md)。背景设置高于 38% 时移入移出保持同值属于预期。

真实反馈覆盖：100/125/150/200% 缩放、负坐标显示器、拔插副屏、最大化重启、跨屏

## 文件选择窗口低频阻塞

Windows 原生文件选择窗口曾低频阻塞，当前没有稳定复现。应用已保持单实例、正确 parent 和后台任务隔离，不增加第二套对话框实现。

重新调查条件：

- 当前版本可稳定复现，或出现可收集的错误/事件日志
- 阻塞影响发布主流程或造成数据损失
- Tauri/dialog/WebView2 上游明确修复相关问题

重新调查时先记录 Windows/WebView2/Tauri 版本、对话框类型、父窗口状态、目标路径类型和阻塞前日志，再决定升级依赖或建立最小复现。

## 分发限制

- 0.1.0 安装包不使用 Authenticode，Windows 首次安装可能显示 SmartScreen 提示；仅从 GitHub Releases 下载并核对 SHA-256。updater `.sig` 仍是自动更新的强制完整性门禁。
